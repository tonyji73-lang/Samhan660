# V1.8 다른 Windows PC 전달용 검수표

현재 결과: **미수행**. 동일 PC의 다른 폴더 실행은 다른 PC 검증이 아닙니다.

- ZIP 이름·SHA256·BUILD_INFO 버전, PC/Windows/GPU, 모니터 해상도와 실제 Windows 배율 기록
- 새 폴더 압축 해제 후 `Samhan660.exe` 실행, 632년 신라 진입
- 1280×720 / 1920×1080 외교 화면의 한글·초상·깃발·버튼·내부 스크롤 확인
- 상대국·행동·사절 변경 시 비용과 실행 가능 여부 갱신 확인
- 친선 사절 → 다음 달 → 통상협의, 확정·취소·Esc·Tab·Shift+Tab·키보드 실행 확인
- 새 슬롯 저장 → 종료 → 재실행 → 국고·관계·협정·사절 월 행동 제한 복원 확인
- 다음 달 협정 해지 → 새 슬롯 저장·재실행 → 해지 상태와 중복 비용 없음 확인
- 닫기 후 지도 입력·월 진행 복구 확인
- 기존 저장을 덮어쓰지 않으며 변경한 Windows 배율은 원래 값으로 복원

교역로 개설 UI는 미연결입니다. 협정만 체결한 상태의 수입 0은 누락 오류가 아닙니다.
결과는 실제 검수한 V1.8 빌드 해시와 함께 기록하세요.
