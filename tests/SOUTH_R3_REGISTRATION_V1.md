## 위치 보정과 남은 원화 문제

대응점은 같은 1254px 비교판에서 수동 판독했다. 대응점을 따르는 메시 보간 잔차 최대 0.08745 native px는 **입력점 적합도**다. 원본이 저해상도이므로 실제 지리 오차·전체 해안 정확도가 아니다. 강 굽이·합류점과 동쪽 곶의 큰 위치 오차는 줄었지만 세부 지류/산릉 차이를 해결하지 못했다.

| 원본 native 범위 [x,y,w,h] | 남은 수정 |
|---|---|
| [600,790,110,100] | 대가야 북서 본류와 동쪽 지류의 분기 간격·폭·연결 |
| [625,900,150,80] | 하구 수로 분기, 작은 섬·바위 형상. 원본 저해상도 때문에 섬의 정확한 개수 확정은 하지 않음 |
| [775,780,64,128] | 곶·안쪽 만 주변의 세부 해안 굴곡, 해변/산림 폭 |
| [675,790,48,48] | 달구벌 (699,814): 성 바닥 둘레의 나무/산릉 |
| [723,801,48,48] | 금성 (747,825): 아래 산릉·바위와 바닥 겹침 |
| [630,827,48,48] | 대가야 (654,851): 보정 후 동쪽 지류가 성 바닥 부근을 지나며 전체 접지 불합격 |
| [580,780,80,160] | x=600의 서쪽 경계, 겹침 x=600..654의 수로 단절 |
| [620,875,180,100] | y=900의 남쪽 경계, 겹침 y=900..954의 하구·해안·색/바다 무늬 |

세 성은 원본도 구릉/물길에 가깝다. 중심점만 마른 땅이라는 이유로 승인하지 않았으며, 성을 이동하거나 지형을 흐리게 덮지 않았다. 비교판의 사각형은 전체 sprite bounds로, 정밀 바닥 마스크라고 주장하지 않는다. 실제 게임의 같은 PNG/피벗/폭으로 육안 확인했다. UV 보정도 일부 산림 모양을 늘리므로 검토용 상태를 유지했다.
