# V1.7.1 다른 Windows PC 전달용 검수표

현재 작업 PC와 다른 PC에서는 아직 실행하지 않았다. 아래 결과를 채워 전달한다. 같은 PC의 다른 폴더 실행은 별도 PC 통과가 아니다.

- PC/OS/GPU: __________
- 모니터 해상도 / 원래 Windows 배율 / 검수 배율: __________
- 실제 게임 창 크기 / ZIP SHA-256: __________

1. 새 폴더에 ZIP 전체를 풀고 `Samhan660.exe`를 실행한다. `Samhan660.pck`를 같은 폴더에 둔다.
2. 신라 캠페인에서 조정을 열어 군주·집단·인물·초상·한글을 확인한다. 720p/1080p에서 내부 스크롤, 선택 표시, 확정·취소·Esc·Tab·Shift+Tab·Space와 닫기 후 지도 선택을 확인한다.
3. 정상 플레이의 미응답 요구/권력 인계 협의를 기존 슬롯과 다른 새 슬롯에 저장한다. 프로그램을 종료하고 다시 실행하여 ID·대상·기한·선택지가 같은지 확인한다.
4. 같은 시작 슬롯에서 보상/기한 보장/강제 회수를 각각 선택한다. 안내 비용·관계·기간을 기록하고 확정 직후 각각 다른 새 슬롯에 저장한다.
5. 각각 종료→재실행→복원→월 진행한다. 국고·충성·협력·영향력·기간·부대/업무 제한을 비교한다. 다시 불러오기만으로 비용/효과가 반복되지 않아야 한다.
6. 실제 Windows 150%에서 글자·장식·클릭 위치·스크롤을 확인하고 원래 배율로 복원한다. viewport 변경만 했다면 DPI 미검증으로 기록한다.
