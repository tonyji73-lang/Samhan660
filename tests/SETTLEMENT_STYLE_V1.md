# 거점 지도 UI 스타일 정리 v1

2026-09-22. 현재 main, 기존 미커밋 세력 선택 UI와 지도 작업 보존.

## 변경

settlement_overlay.gd만 표시·복귀 연결을 수정했다. 먹색101b1a, 금색c2a36a, 적갈색6f261e와 세력 선택 UI의 글꼴을 사용한다.
상단은 세력/날짜, 국고/세력 군량, 침공 예고 건수, 저장·메뉴로 분리했다. 수치는 campaign의 현재 gold/food 및 날짜를 읽는다. 침공 건수는 기존 Invasions.pending에서 아군을 대상으로 한 명령만 집계하고 기존 목록을 연다. 예고 상세는 툴팁에서 확인한다.
왼쪽 영지·군사·생산·인사는 동일 크기이며 마지막 선택 메뉴를 적갈색으로 표시한다. 아군/종료 상태 등의 기존 명령 자격은 유지했다.
하단은 선택 성, 주둔 병력·도시 군량, 지원 출발지·경로·예상 도착, 턴 종료로 나눈다. 지원은 기존 부대 창과 이동 명령, 턴 종료는 기존 월 처리 함수를 호출한다.
지도 비교 기능은 별도 도구 줄로 보존했다. 이미지·성 좌표·r3와 자동 LOD는 변경하지 않았다. 지원 안내를 두 줄로 줄여1280 화면의 지도 영역을 확보했다.
메뉴를 열 때 거점 지도를 닫는 대신 일시 숨기고 팝업/확인 창이 닫히면 돌아온다. 첫 진입 이후 전체 지도 왕복에서도 지도 카메라를 임의 초기화하지 않는다. 기존 명령 창 복귀 시 선택 성·지도 위치 보존.

## 실제 실행

tests/settlement_style_v1_test.gd, Godot4.7.2 D3D12 GUI 자동 입력. 실제 타이틀→새 UI→642 신라→거점 지도 경로로 시작했다.1280×720/1920×1080에서 달구벌·금성·실직·울릉·국원·하슬라 선택, 확대/드래그, 네 메뉴 왕복, 저장·메뉴/침공 목록 왕복, 지원 경로·취소, 하단 배치를 검사했다.
국고·군량 표시를 실제 값과 대조하고 표시/메뉴만으로 캠페인 상태가 바뀌지 않는지 확인했다. 정상 군사 명령으로 금성 부대를 달구벌에 지원 발령하고 다음 달 도착을 검사했다. 사용자 슬롯 대신 고유 시험 슬롯을 저장했다. 실제 턴 종료를 두 해상도에서 각각 실행했다.
침공 목록은 실제 시험 중0건 상태에서 진입·복귀했다. 새 자연 침공 발생이나 방어전은 이번 스타일 검증으로 주장하지 않는다. 사람의 수동 플레이와 새 프로세스 저장 복원은 이번에 실행하지 않았다.
