# 642년 신라 군권 인계 정상 진행 검증 v1

검증일: 2026-09-17. 기준 main `d103a9d`. Godot 4.7.2 Windows GUI 및 headless. 기존 642 정치·군사 준비·귀족 권력 제약 기록을 읽고 진행했다. 집단은 게임용 분류다.

## 정상 명령으로 협상 발생

새 642년 7월 신라, 역사 난이도로 시작했다. 기존 저장 출처에 의존하지 않는다. 인물·병력·영향력·국고·날짜를 주입하지 않았고 AI와 월 결산을 유지했다. 반복 재현을 위해 난수 시드만 고정했다(집결 64220260919, 선택 분기 64220260920).

1. 공통 인사 명령으로 김유신을 금성 태수와 기존 금성 부대 지휘관에 임명했다.
2. 아군 도시의 무지휘관 부대를 정상 분할·병력 이동 명령으로 금성에 모았다. 각 출발지에 1,000명을 남기고 기존 경로를 한 달에 한 구간 이동했다. 금성 도착 부대를 기존 김유신 부대에 정상 병합했다. 이동·병합 기록 31개와 분할 검증은 실행 JSON에 남는다.
3. 642.7 군사 집단 지휘 병력 28,000명/영향력 20.4494 → 642.8 55,000명/31.7237 → 642.9 112,400명/55.6968. 실제 월 진행 **2회**로 기존 문턱 40을 넘었다.
4. 금성 주력에서 정상 명령으로 1,000명(`unit:82`, 장비 1,000, 훈련 50)을 분할했다. 나머지 111,400명은 김유신 지휘를 유지한다. 해당 1,000명의 지휘관을 선덕여왕으로 교체하는 부대 화면 명령에서 `handover:1`이 발생했다. 선택 전 국고와 지휘관은 유지된다.

8월 자연 발생 인사 요구는 거절, 9월 흉작은 세금 유지로 선택했다. 협상 직전 김유신 충성 58, 군사 집단 협력 48, 선덕여왕 충성 50, 왕실 협력 50, 국고 3,467이었다. 실제 완료 월 세입 평균 M=1,233.5, 영향력 감소 D=0.3412969, 조정 F=0.96으로 기존 최소 보상금 **100**, 보장 기간 **2개월**이 산출됐다. 전체 집결 병력이 아니라 1,000명의 군권만 회수하므로 보상금이 작다.

이는 정상 명령으로 의도적으로 유도한 협상이다. AI가 자발적으로 협상을 요청한 사례나 일반적인 전략 추천으로 해석하지 않는다. 병력을 집중하는 동안 AI가 계속 행동해 영토·국가 총병력이 변했다. 이후 월의 집단 영향력 전체 변화는 협상 효과만을 나타내지 않는다.

## 동일 협상 직전 저장의 세 분기

각 분기마다 같은 `before` 저장을 다시 불러와 전체 게임 상태 일치를 검사했다. 아래 정치 변화는 인계 시점의 효과다.

| 선택 | 실제 협상 지출 | 인계 완료 | 김유신 충성 / 군사 협력 | 선덕여왕 충성 / 왕실 협력 | 해당 부대 출정·훈련 제한과 회복 |
|---|---:|---|---|---|---|
| 보상 | 금 100, 국고 3,467→3,367 | 642.9 즉시 | 58→54 / 48→46 | 50→58 / 50→54 | 인계 차질 없음. 선택 직후 공통 출정 후보·훈련 자격 통과 |
| 기한 보장 | 금 0 | 642.11, 실제 2개월 후 | 대기 중 58 / 48, 완료 시 54 / 46 | 대기 중 50 / 50, 완료 시 58 / 54 | 대기 자체의 출정·훈련 차질 없음. 10월까지 김유신 지휘, 11월 월 처리에서 인계 |
| 강제 회수 | 금 0 | 642.9 즉시 | 58→38 / 48→36 | 50→58 / 50→54 | 선택 직후 출정 후보 제외·실제 훈련 명령 거부. 다음 1회 월 처리 동안 제한, 642.10 결산 종료 후 해제 |

강제 회수의 거부된 훈련은 국고·업무 등 전체 상태를 바꾸지 않았다. 강제 차질 중 방어·아군 이동 허용은 기존 규칙이며, 이 정상 분기에서 별도 방어전이나 이동을 실행한 결과로 보고하지 않는다. 기한 대기에도 담당자 업무·군량 등 일반 자격 조건은 적용된다.

출정 검증은 공통 `Army.attack_units`의 해당 부대 포함 여부다. 세 분기에서 실제 공격 전투를 추가 실행한 검증은 아니다. 훈련은 세 분기 모두 비교를 위해 11월까지 기다린 뒤 GUI 명령으로 실제 시작했고, 12월에 금 50 지출과 훈련 **50→61**을 확인했다. 이는 최초 재개 가능 시점을 뜻하지 않는다(보상은 즉시, 강제는 10월 결산 직후 가능). 새 캠페인 시작부터 이 훈련 확인까지 각 분기의 실제 경과는 5개월이다.

국고 검산: 10월 보상 4,272 / 기한·강제 4,372, 11월 보상 5,044 / 기한·강제 5,144, 12월 훈련 결산 후 보상 5,637 / 기한·강제 5,737. 월 세입·유지비와 실제 AI 처리를 포함한 값이다. 후임 임명 효과는 기존 공통 인사 반응과 간격 제한을 그대로 사용했다.

## GUI에서 발견하고 수정한 연결 문제

- 고정 좌표의 후임 선택란이 협상 상태·기한 본문과 겹쳤다. 본문을 스크롤 영역으로 두고 그 아래 선택란을 배치했다.
- 강제 회수 완료 후 차질이 해제되어도 미래 1회 제한 문장이 남았다. 접수 당시 견적과 현재 상태를 구분하고 현재 부대별 차질을 공통 상태에서 조회해 표시한다.
- 인계가 끝난 뒤에도 닫기 버튼이 ‘기존 권한 유지’라고 표시됐다. 완료 후에는 ‘닫기’, 미완료에는 ‘닫기·기존 권한 유지’로 표시한다.
- 선택 전 A/B/C 실제 금액, 완료 월, 현재 당사자 충성·집단 협력을 표시했다. 문턱·비용·정치 효과·전투 공식·업무 처리 순서는 바꾸지 않았다.

GUI 자동 입력으로 부대 화면 지휘관 변경, A/B/C 선택, 재진입, 닫기 후 지도 입력 잠금 해제, 훈련 명령을 확인했다. 주 화면은 마우스 입력, 별도 네이티브 협상 창은 버튼 포커스 후 Enter 입력을 사용했다. 협상 창 자체의 Viewport를 캡처해 대기 선택란, 강제 선택 직후, 다음 월 회복 표시를 육안 검토했다. 사람의 수동 플레이와 구분한다.

로컬 실행 증거(생성물, Git 미포함): `.godot/silla-642-handover/normal.json`, `restart.json`, `wait-selected.png`, `force-selected.png`, `force-month1.png`, `restart-wait*.png`, `restart-force*.png` 및 같은 폴더의 나머지 분기 캡처.
