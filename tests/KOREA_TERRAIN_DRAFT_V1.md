기존 세계 표시 사각형을 R, 세계 UV를 u라 하면 성 접점은 `R.position + u * R.size`이다. PNG 위치는 `R.position + (2048,1024)/(6144,4096)*R.size`, 크기는 `(2048,3072)/(6144,4096)*R.size`다. 성 스프라이트의 (0.5,0.67) 지점, 도로 끝점, 선택 원, 클릭 버튼은 같은 변환을 사용한다. 미리보기에서만 축소 하한 0.2를 허용하고 전체 맞춤을 제공한다. 기존 UV·ID·연결·마스크·저장 형식과 게임 규칙은 수정하지 않았다.
