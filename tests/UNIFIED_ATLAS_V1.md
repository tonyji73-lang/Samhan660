# 밝은 아틀라스 플레이 지도 통합

2026-09-23. 작업 폴더: `Samhan660-faction-rulers-v1/.worktrees/project-foundation-v1`, main, 기준 HEAD `f5a5c73121ff0232027dee0633977fa3bc3288d7`. 기존 미커밋 Light Atlas 변경 위에 적용했다. 적용되는 AGENTS.md는 프로젝트와 상위 경로에서 발견되지 않았다. 이번 요청에는 커밋·Push가 없으므로 작업 트리에서 보존한다.

## 동작과 정리 범위

- F5 → 새 캠페인 시작과 타이틀/캠페인 메뉴의 저장 불러오기가 밝은 아틀라스로 직접 진입한다. ‘전체 지도’는 같은 지도 인스턴스의 전체 범위 축소다. Esc는 캠페인 메뉴를 연다.
- 일반 플레이에서 옛 지도 전환 버튼/메뉴 항목과 후보·r2/r3 비교 패널 생성을 제거했다. 검토 기능은 명시적 실행 인자 `-- --map-review`에서만 접근한다. 게임 모드나 캠페인은 추가하지 않았다. 지형·보정 메시·원본/성 좌표·지원 경로·자동 LOD 꺼짐을 유지한다.
- 명령창 뒤에 아틀라스를 유지하되 모달 차단막과 재귀 마우스 비활성화로 조작을 막는다. 720p 지원 안내 툴팁이 군사창 위에 남는 문제도 수정했다. 닫으면 같은 성과 카메라를 유지한다.
- 공통 지원 창을 ProductionLayer로 옮겨 아틀라스 위에서 사용한다. 외부 도시 선택(침공 화면 등)은 아틀라스 선택에도 전달한다. 명령 결과 로그도 아틀라스에 표시한다.
- 같은 성을 다시 선택하는 공통 명령의 데이터 갱신은 카메라/경로 초기화와 분리했다. 새 성 선택에만 카메라를 이동한다.
- 이벤트 카메라/거점 강조를 실제 아틀라스의 등록 좌표에 연결하고 입력 잠금·카메라 복귀를 유지한다. 한국 아틀라스 밖 산동항은 가짜 좌표로 옮기지 않는다. 고구려 도입부의 평양 목적지 연출은 유지하지만 지도 밖 출발지에서 오는 경로선은 표시하지 않는다. 등록된 영토 폴리곤이 없으므로 옛 마스크 경계를 덧씌우지 않고 지도상의 소속 거점을 강조한다.
- 저장에 선택적 `atlas_view`(성·배율·중심·성 정보창 표시)를 추가한다. 이벤트 중 저장은 연출 전 카메라를 사용한다. 이 항목이 없는 저장도 기존 게임 상태를 보존하고 선택 성 중심으로 연다. 카메라는 원본 좌표 0.001px 허용 오차로 비교한다.
- 옛 화면으로 가는 실행 경로/버튼/close 메서드는 제거했다. 숨긴 MainVBox/MapArea는 공통 명령 UI 바인딩, 세계 좌표/마커 데이터, 시나리오 및 검토 도구가 아직 참조하므로 삭제하지 않았다. 참조가 남은 지도 PNG·마스크·보정 자산도 보존했다. 참조 감사 없이 자산을 일괄 삭제하지 않았다.
