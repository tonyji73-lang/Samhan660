# V1.10 짧은 첫 플레이 검수표

실행: ZIP을 모두 풀고 `Samhan660.exe`를 실행합니다. 기존 저장 대신 새 슬롯을 사용하세요.

- [ ] 새 캠페인에서 632년 신라를 선택하고 금성을 확인한다.
- [ ] 영지 → 담당자 선택 → 견적 확인 → 개발 지시를 찾는다. 선택·취소만으로 돈이 줄지 않는지 본다.
- [ ] 생산에서 현지 군량·철·무기를 확인하고, 필요한 기술·시설·담당자 버튼을 찾는다. 예약과 실제 생산은 다르다.
- [ ] 수송할 출발 도시와 화물을 골라 비용·도착 조건을 읽는다. 도착 전 화물을 현지 재고로 세지 않는다.
- [ ] 군사에서 부대와 장비 지급 미리보기를 확인한다. 훈련은 인원·병종·담당자·자금 조건을 읽고 접수한다.
- [ ] 월 보고·다음 행동에서 현재 업무, 조정·외교의 경로를 찾는다. 화면을 여는 것만으로 명령이 실행되지 않는지 본다.
- [ ] 다음 달을 누르고 월 보고에서 국고 전후, 업무 완료, 생산 보류 및 수송 기록을 확인한다.
- [ ] 보고서를 스크롤하고 Tab·Shift+Tab·Enter·Esc를 써 본다. 닫은 뒤 지도를 선택한다.
- [ ] 새 파일명으로 저장한 뒤 종료·재실행·불러오기를 한다. 날짜·국고·담당자·월 보고를 비교한다.
- [ ] 패전 기록이 있으면 전투 결과 → 보충 → 장비·훈련을 따라가며 선택 부대가 유지되는지 본다.

사람의 첫 플레이 평가에 기록할 것: 처음 찾기 어려웠던 버튼, 이해하기 어려운 문구, 화면 왕복 횟수, 포기한 행동과 이유. 에이전트 검수와 별도로 기록합니다.

다른 PC 전달 시: 빌드 V1.10의 BUILD_INFO와 SHA256, Windows 버전, 모니터 해상도, 실제 Windows 배율, 게임 창 크기를 기록하세요. 같은 PC의 다른 폴더 실행은 다른 PC 검증이 아닙니다.
