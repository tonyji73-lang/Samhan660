Samhan660 — V1.6.1 Windows x86_64 검수용

1. ZIP 전체를 쓰기 가능한 새 폴더에 압축 해제하세요.
2. 실행할 파일의 정확한 이름: Samhan660.exe
3. Samhan660.pck와 함께 두세요. EXE만 다른 곳으로 옮기면 실행할 수 없습니다.
4. Godot 편집기 설치는 필요하지 않습니다.
5. 새 게임 → 632년 → 신라 → 금성에서 시작합니다.
6. 화면 크기는 창 크기를 조정해 확인할 수 있습니다. Esc는 현재 업무 창 닫기/이전 화면, Tab/Shift+Tab은 선택 이동, Space는 선택된 버튼 실행입니다.
7. 기본 저장 경로: %APPDATA%/Godot/app_userdata/Samhan660/
   이전 실행본과 저장 경로를 공유합니다. 검수는 새 슬롯을 사용하고 기존 저장을 덮어쓰지 마세요.

V1.6 군수·편성·훈련 UI가 포함됩니다. 게임 데이터·장식·본문/제목 폰트는 PCK에 포함됩니다.
licenses 폴더에 엔진·폰트·아이콘 라이선스를 제공합니다.
기존 V1.5 ZIP은 그대로 보존했습니다. 소스 기준과 해시는 BUILD_INFO.json 및 SHA256SUMS.txt를 참고하세요.
검수용 PCK에는 명시적인 --qa-v1-6-1 옵션에서만 동작하는 검사 노드가 있습니다.
일반 더블클릭 실행에서는 검사 노드가 즉시 제거되며 자동 조작이나 자동 저장을 하지 않습니다.

별도 PC 실행·저장·복원은 아직 미검증입니다. OTHER_PC_CHECKLIST.md를 사용해 확인해주세요.
서명되지 않은 검수 빌드입니다. Windows가 안내를 표시하면 파일 출처와 체크섬을 확인하세요.
