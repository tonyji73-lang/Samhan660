# 남부 v3 일반 플레이 부분 적용 — 2026-09-23

## 적용과 실제 표시 범위

main의 기존 미커밋 전 권역 R3·남부 v2 작업 위에 별도 자산으로 추가했다. 소스 PNG와 성 위치는 수정하지 않았다. 일반 새 캠페인의 금성·달구벌 내륙은 확대하면 `south_continuous_v3`가 자동 표시된다. 전체 남부 패치 승인으로 해석하면 안 된다.

## 렌더 연결

- `ui/korea_layout_v1/approved_korea_map.gd`: 기존 지형 그리기를 전용 자식 CanvasItem으로 분리. 바탕 원본 → 기존 승인 지형 → v3 → 영토/지원 경로/성/이름 → UI 순서 유지.
- `ui/korea_layout_v1/south_v3/integration/terrain_canvas.gd`, `south_v3_layer.gd`: v3 전용 CanvasItem에만 패키지 셰이더 연결. 성·클릭 영역·지도 전체/UI에는 재질 없음.
- `ui/korea_layout_v1/south_v3/assets/`: 실제 v3 1346×1168 PNG와 선형 렌더 데이터용 300×260 바다 마스크. import `size_limit=0`, 무손실. 실행 시 원본 크기의 ImageTexture와 밉맵을 생성하고 선형 밉맵 필터 사용.
- `south_v3/inland_registration.json`: 2픽셀 간격 메시의 위치/UV는 동일, 승인 경계의 alpha만 제한. 생성 도구는 `tests/build_south_v3_region.py`.
- `full_r3_v1/registration_review.json`: PNG·메시·셰이더·바다 마스크 해시에 묶은 부분 승인 추가. 기존 제주 항목 유지. 패키지의 전체 승인 false 플래그를 일괄 변경하지 않음.
- 일반 LOD는 실제 화면 픽셀/원본 픽셀 밀도에 `smoothstep(1.8,2.6,밀도)` 적용. 매 동기화마다 실제 ShaderMaterial의 `lod_weight`에 전달. 축소 0, 확대 도중 중간값, 근접 1 확인. 리뷰와 v2/기존 비교 화면의 중복 렌더 방지.
- 셰이더 외곽 폭은 원본 4픽셀, 바다 마스크 활성화. 정상 플레이의 부분 메시에는 해안이 제외되어 있으므로 바다 처리 효과는 전체 패치 검토 화면에서 별도로 확인했다. 영토·육지·경로 판정에 마스크를 사용하지 않는다.
