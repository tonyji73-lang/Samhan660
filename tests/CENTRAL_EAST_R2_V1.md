# 중부·동해 r2 실제 연결 검증

2026-09-22. 현재 main과 기존 미커밋 변경을 유지했다. 바탕화면 폴더 대신 Downloads/Samhan660_Central_East_Detail_v1 (1).zip에서 VSCODE_REQUEST.txt, START_HERE_KO.md, integration/INTEGRATE_KO.md, manifest와 보정 코드를 읽었다. 패키지 비교 이미지는 Godot 실행 증거로 사용하지 않았다.

## 적용

- 기존 approved_korea_map.gd에 지속 보관하는 draw-only 보조 객체를 연결했다. 원본 다음, 영토·지원 경로·성·글자 이전에 보정 망을 그린다. 미보정 후보와 보정 망은 상호 배타적이다.
- settlement_overlay.gd에 보정 보기 / 원본 보기 버튼을 추가했다. 비교 상태에서 닫기·재열기 시 기존 코드가 카메라를 초기화하던 문제를 수정했다.
- central_east/integration/central_east_display_layer.gd 및 data/central_east_display_mesh.json을 추가하고 r2 manifest·안내를 반영했다. 보조 객체에 기존 런타임 밉맵 텍스처를 공유해 미보정/보정 상태의 필터 정책을 유지했다.
- 두 PNG는 패키지와 바이트 동일 확인 후 재사용했다. 승인 원본 SHA256 36594c1d1ee0cbcd80a175d72790d3e22423103cf81d6b191f8bf2d317e1f246, 후보 SHA256 20be0889282839a2555d87b67777aa83be00dee6375268889e83182caa0f9a5f.
- 성 좌표·크기·선택·게임 규칙·저장 형식은 변경하지 않았다. production_auto_switch_allowed=false 유지. 기본은 승인 원본이다.

## 여는 방법

F5 → 642년 신라 → 거점 지도 → 중부·동해 → 후보 보기 또는 보정 보기. 원본 보기로 복귀한다. 세 상태 모두 같은 카메라에서 비교한다.

## 실제 검증

Godot 4.7.2, D3D12, 642년 신라. tests/central_east_r2_test.gd의 GUI 자동 입력·엔진 캡처이다. 사람의 수동 플레이가 아니다.
1280×720 및 1920×1080에서 줌1/5/10 원본·미보정·보정 캡처, 동일 카메라, 6개 거점 클릭, 지원 경로, 하단 UI, 닫기/재열기, 휠 입력과 자동 전환 차단을 검사했다. 보정 망5808개 삼각형 및 정점 alpha의 투명 경계/가시 내부를 엔진에서 확인했다. 미래 LOD의 메모리 통제 조건 검사는 실제 자동 전환 승인과 구분하며 검사 후 복구한다.
첫 실행에서 닫기/재열기 카메라 유지 검사2건이 실패하여 위 표시 코드를 수정했다. 최종 결과는 .godot/r2-final.log와 .godot/central-east-r2/result.json에 기록한다.
사용자 기본 저장 SHA256은 기존 3bca5c5286be3abb44ed60fbb9e1efe39815c29f6ff255d2ad825273aa5275d3과 동일했다. 이번에는 새 프로세스 저장 복원이나 전체 게임 회귀를 실행하지 않았다.
