# 동해 상세 확대·축소 표시 수정

2026-09-18. 기존 main의 미커밋 지도 작업을 보존하고 표시만 수정했다. 앞선 EAST_COAST_DETAIL_DRAFT_V1.md의 실행 기록은 당시 상태로 보존한다. 이 문서가 현재 성 크기 규칙과 후속 검증 결과다.

## 변경

- `settlement_map.gd`: 성 그림의 기존 24~120px 제한을 제거했다. 성 폭은 항상 `130 * 전체 월드 화면 폭 / 6144`이며 지면 접점 (0.5,0.67)은 기존 세계 UV에 고정된다. 화면 폭 40px 미만에서는 성 그림 대신 중심에 12px 마름모 거점 표식을 그린다. 표식은 축척에 맞춘 건물 그림이 아니라 위치 표시다.
- 클릭 버튼의 크기는 그림과 독립적으로 최소 32px를 유지한다. 최소 클릭 영역이 성 그림을 키우지 않는다. 기존 한국 시안에서 겹친 클릭 영역을 가까운 버튼 중심에 배정하는 오선택 방지 로직도 유지했다. 선택 원과 글자 간격은 표식/그림 크기에 맞춘다. 같은 거점 표시 클래스를 사용하는 기존 거점 지도에도 이 그림/클릭 분리가 적용된다.
- 한국 개관 PNG와 동해 상세 PNG의 `.png.import` 두 파일에서 mipmaps/generate를 활성화했다. 기존 선형 밉맵 필터를 통해 **선택한 동일 PNG의 해상도 단계**를 사용한다. PNG 자체는 수정하지 않았다. 확대·축소에 따라 다른 해안·강·섬 그림으로 교체하지 않는다. 상세 비교 버튼을 명시적으로 켜거나 끄는 경우에만 후보가 바뀐다.
- `tests/east_coast_detail_test.gd`: 독립된 성 그림/클릭 크기·표식·원본 픽셀·밉맵·연속 배율 검사를 추가하고, 산출물을 `.godot/east-coast-zoom/`에 분리했다.

열기: F5 → 642년 신라 → 거점 지도 → 한국 시안 → 상단 동해 상세. 전체/휠/선택 성으로 배율을 조절한다.

## 실제 실행

Godot 4.7.2 D3D12에서 새 642년 신라 캠페인을 시작하고 GUI 자동 입력·자동 캡처로 검사했다. `--path . --script res://tests/east_coast_detail_test.gd` 실행 **198 checks, 0 failures**. 최종 로그에 ERROR/WARNING 없음. 게임 규칙 회귀 수치를 가져온 것이 아니다. 사람의 수동 플레이나 편집기 F5 키 입력 자체를 검증한 것은 아니다.

- 1280×720 및 1920×1080, 실직·금성·울릉의 전체 맞춤/중간 3/확대 5에서 버튼 중심과 실제 지면/표식 위치를 클릭했다. 매번 실제 드래그 이동을 확인한 다음 선택했고 모두 정확한 거점으로 연결됐다.
- 성 그림 지면 접점과 클릭 버튼 접점이 기존 UV에 일치했다. 숨겨진 축소 성의 계산 폭까지 포함하여 모든 측정의 월드 폭은 130이었다. 축소 시 실제 화면은 작은 표식이다.
- 0.3→0.7→1→2→3→4→5→2→0.7 연속 배율에서 상세 표시 상태와 개관/상세 Texture2D 객체가 유지되고 상세 타일의 역변환 월드 위치도 동일했다. 원본과 디코딩 픽셀 비교, 생성 밉맵 존재, 실제 캡처를 함께 확인했다. 따라서 배율 변경에 의한 다른 지형 원본으로의 교체는 없다. 밉맵 필터링에 따른 작은 픽셀 혼합은 같은 지형의 축소 표현이다.
- 두 해상도 하단 UI 화면 내 배치, 비교 켜기/끄기, 기존 지도 복귀 검사 통과. 캠페인 전체 데이터의 전후 동일성도 통과했다.
