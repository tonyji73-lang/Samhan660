# Living City V1.2 — 시각 검토

final result: passed (요청한 세 화면 개선 범위)

## 비교 대상과 근거

승인된 1번 Living City의 `domestic_default.png`, `approved_personnel.png`(1672×941)를 기존 패키지에서 사용했다. 실제 앱은 632년 신라·금성 새 캠페인이다. 시안의 642년 예시 데이터와 같은 수치로 만들지 않았다.

`tests/living_city_v1_2_review/`에 1280×720, 1920×1080의 내정 기본·담당자 선택·태수 임명 화면을 수정 전후 모두 남겼다. before-after-화면-해상도.png는 왼쪽 V1.1/오른쪽 V1.2, reference-화면-해상도.png는 왼쪽 승인 시안/오른쪽 구현이다. 시안만 같은 표시 크기로 정규화했고 게임 캡처의 종횡비를 바꾸지 않았다. Godot canvas_items 논리 기준은 1920×1080이며 웹 DPR은 해당하지 않는다.

담당자 카드 선택 전용 시안은 없으므로 내정 기본 시안과 도시/업무 비중·색·위계를 비교했다. 이 비교판은 동일 조작 상태의 픽셀 비교가 아니다. 수정 전후 비교판은 각각 드롭다운과 새 카드 선택 상태를 보여준다.

비교판과 원래 크기 720p 렌더링을 함께 열어 글자, 관모·얼굴, 요약 칸, 버튼·하단 메뉴, 후보 목록을 확인했다. 1080p 전후 비교도 확인했다. 선덕여왕/김춘추/김유신 개별 선택 캡처와 많은 후보·빈 목록·긴 이름 상태를 직접 열어 검토했다. 720p 전체 이미지에서 해당 부분을 읽을 수 있어 추가 확대 크롭은 만들지 않았다.

## 발견·수정·재검증

- 선덕여왕: 큰 초상 표시 범위를 832×832에서 610×610으로 좁혀 얼굴·어깨 비중을 약 1.36배 높였다. 작은 초상은 별도 480×560 범위를 사용한다. 비율을 유지하고 관모/얼굴을 포함한다. 다른 두 후보의 기존 초상과 이어지는 크기를 확인했다.
- 담당자 선택: 패널 내부 카드에 초상·이름·정치/지력·현재 업무·배정 가능 여부를 표시한다. 현재 태수는 상단 요약으로 유지하고 중복된 큰 태수 초상은 접어 정상 후보 3명이 한 번에 보이도록 정리했다. 많은 후보는 내부 스크롤한다.
- 견적: 필요 금, 완료 예정, 예상 성과를 독립 요약 칸으로 만들었다. 처음 두 줄 날짜로 표시했을 때 보조 버튼이 하단 메뉴와 겹쳐 한 줄 날짜로 정리했다. 최종 bounds와 실제 캡처에서 겹침이 없다. 사유는 확정 가까이, 위치·직책·세부 정보는 요약 아래에 둔다.

## 다섯 시각 항목

- 글꼴: 기존 한글 폰트 유지. 초상 이름36, 능력29, 요약 값30/날짜26, 본문22 논리 px. 720p에서 주요 수치·날짜·조작 문구를 확인했다.
- 배치: 도시65%/업무35%, 기존 전경과 상하단 유지. 후보 카드 목록이 패널 안에서 스크롤하고 취소/닫기는 하단 메뉴 위에 남는다. 기본 화면의 확정도 고정 영역에 남는다.
- 색: 크림 패널, 어두운 프레임, 금색 선택 테두리/문구, 붉은 실행 버튼. 불가 사유는 붉은 본문이며 선택과 실행 가능 여부를 구분한다.
- 이미지: 원본 수정 없이 AtlasTexture 범위만 조정했다. 선덕여왕 투명 오버레이와 다른 장수의 기존 사각 초상·도시 이미지를 그대로 쓴다. 새 얼굴/장식은 제작하지 않았다.
- 내용: 금100/632년2월/성과+5는 실제 견적 값이다. 후보별 미래 세입·수확 수식을 추가하지 않았다. 카드 선택은 견적만 바꾸며 개발 지시에서 접수한다. 후보 없음과 배정 불가 이유도 표시한다.

## 검증 및 남는 차이

이번 최종 GUI 실행 167개 통과, 실패0. 기존 내정 회귀를 새로 실행해 131개 통과, 실패0. git diff --check 통과. GUI 숫자에는 캡처와 배치 검사가 포함된다. 최종 로그에 스크립트 오류는 없으며 Windows 루트 인증서 경고는 남는다.

목재·금속 장식, 광택, 서예 제목은 후속 자산 제작이다. 김춘추/김유신 사각 배경, 실제 게임 정보와 스크롤 구성은 원본 시안과 다르다. 금성 외 전경은 미제공이다. 픽셀 단위 시안 복제가 아니라 요청한 V1.2 개선 범위의 통과 판정이다.

권력 인계 모든 분기, 해임 확정 GUI 전체 경로, 생산 전체 분기, export, 장시간 수동 플레이는 미검증이다. 상세 보고서는 `tests/LIVING_CITY_UI_V1_2.md`에 있다. V1.1 QA는 `tests/living_city_v1_1_review/design-qa.md`에 보관했다.
