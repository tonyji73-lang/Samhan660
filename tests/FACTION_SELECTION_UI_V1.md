# 세력 선택 UI v1 실제 게임 연결

2026-09-22. 지정 이름 대신 다운로드 폴더에서 확인된 Samhan660_Faction_UI_v1.zip을 사용했다. VSCODE_REQUEST.txt, README_KO.md, integration/CONTROLLER_CONTRACT_KO.md를 읽었다. 현재 main과 기존 미커밋 지도 작업 보존. project.godot나 캠페인 규칙은 덮어쓰지 않았다.

## 변경

- ui/faction_selection_v1/: 패키지 표시 컴포넌트·자산·폰트/OFL·전용 셰이더 추가.
- new_game_setup.gd: 기존 진입 경로에 View 설치. 선택 요청은 기존 시나리오/세력/역사·가상/난이도 처리 함수에 전달하고, 현재 ScenarioData로 모델을 갱신한다. 기존 컨트롤러와 시작 함수, 씬 전환·설정 전달·음악·페이드를 유지한다.
- 632 신라에서 패키지 선덕여왕 초상·궁궐·다섯 열 창작 선언문을 표시한다. 다른 세력은 기존 군주 초상과 배경/설명을 사용하며 선덕 초상을 대신 넣지 않는다. 승인 지도는 장식용이며 확정된 금성 좌표만 표식으로 표시한다.
- 예시 ID와 미리보기 잠금 목록은 사용하지 않았다. 실제 활성/잠금 목록, 군주·수도·인물·영지는 기존 데이터에서 가져온다. 패키지에 없는 시작 자원 수치를 만들어 표시하지 않았다.
- 기존 시작 함수를 호출하기 직전에 4개 선택 ID와 사용 가능 여부를 재검증하고 기존 menu_locked와 View busy로 중복 시작을 막는다. 씬 진입 실패 시 다시 활성화하고 오류 문구를 표시한다.
- 패키지 지도 셰이더의 source_color 예약어 충돌을 sampled_color로 수정했다. 기존 긴 선언문은 종이 영역을 벗어나 패키지의 짧은 승인 창작 문구를 사용했다. 캠페인 지도 셰이더는 변경하지 않았다.

## 실행

F5 → 새 게임. 기존 세력 선택 진입 경로에서 새 화면이 나온다.
검증 스크립트:tests/faction_selection_ui_v1_test.gd. 실제 Godot4.7.2 D3D12 GUI 자동 입력이며 사람의 수동 플레이와 구분한다.
두 해상도1280×720/1920×1080, 실제 버튼 선택·설명 휠 스크롤·Esc 타이틀 복귀·재열기, 전체 시나리오의 사용 가능 세력과 군주·수도 일치를 검사한다. 632 신라 시작 및 거점 지도 진입, 642 백제·가상·어려움 시작의 설정 전달을 확인한다.
최종 로그:.godot/faction-ui-final.log. 실제 캡처:.godot/faction-ui-v1/1280-632-silla.png 및1920-632-silla.png. 패키지 정적 미리보기를 실행 증거로 사용하지 않았다.
