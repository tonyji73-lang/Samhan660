# 남부 R3 원화 수정 전달 자료

승인 원본과 기존 후보의 **동일 지도 범위** 비교 자료다. 원화 수정 완료본 또는 자동 LOD 승인본이 아니다. Part1/Part2의 13 PNG를 SHA256으로 확인했고 현재 자산과 모두 같아 재적용하지 않았다.

기준: 승인 지도 1254×1254, 좌상단 (0,0), 우측 +x/아래 +y. `issues.json`의 rect는 [x,y,폭,높이]. 세계 6144×4096의 UV가 아니다. 주 타일 detail_2_2 범위는 [600,600,354,354], 실제 원본은 1254×1254다. 좌측 detail_2_1=[300,600,354,354], 아래 detail_3_2=[600,900,354,354], 좌하단 detail_3_1=[300,900,354,354]. 제주의 검증된 패치는 변경하지 말 것.

## 파일 읽기

- `NN-...-approved.png`와 `NN-...-candidate.png`: 같은 범위·같은 출력 크기, 표시 없는 이미지. 작은 원본의 비교용 확대는 신규 고해상도 제작이 아니다.
- `*-approved-native.png`: 승인 원본의 픽셀을 리사이즈 없이 추출한 무표시 크롭.
- `*-uv-review.png`: **검토용 메시를 적용한 계산 이미지**. 원화 수정의 원본으로 쓰지 말 것. 섬·물길 구조의 차이는 남아 있다.
- `*-comparison.png`: 승인/미보정 후보/UV 보정 검토 순서. 빨간 상자는 문제 범위다. 이는 진단 렌더이며 실제 게임 실행 증거가 아니다.
- `*-castle-context.png`: 동일 좌표 위에 현재 성 PNG, 현재 폭, 현재 피벗(0.5,0.67)을 그대로 그린 비교판. 청록 사각형은 스프라이트 전체 범위이며 바닥 마스크가 아니다. 물/산/나무와 바닥 전체가 안전하다는 판정 자료가 아니다.
- `tile-*.png`: detail_2_2 전체 무표시 비교와 25 native px 간격 격자. 첫 선 (600,600), 마지막 선 950.
- `uv_landmarks.json`: 손으로 식별한 대응점 12곳, 보정 결과와 제한. 잔차는 메시가 입력 대응점을 얼마나 따르는지이며 지리 정확도가 아니다.
- `repack_audit.json`: 새 ZIP은 추출/재적용하지 않고 내부 PNG만 읽어 CRC/해시 대조.
- `game_captures/`: 실제 642 신라 Godot 창의 자동 입력 캡처. `base`=승인 지도, `raw`=미보정 상세, `uv`=검토 메시. 같은 성·배율·해상도의 세 파일은 카메라가 같다. `wide`에서는 배율에 따라 상세 가중치가 0일 수 있다. `results.json`에 실제 배율/가중치/카메라가 있다. 사람의 수동 플레이가 아니다.

## 수정 요청

1. 강 합류점 [600,790,110,100]: 큰 위치는 보정 가능하지만 분기 간격과 폭까지 승인 원본에 맞춰 재작성. 상세 원화의 선명함은 유지.
2. 하구/섬 [625,900,150,80]: 승인 원본에 없는 작은 섬·바위 및 달라진 수로 연결을 정리. 원본이 저해상도라 불확실한 세부를 확정된 지리로 표현하지 말 것.
3. 동해안 [775,780,64,128]: 곶 끝·안쪽 만·아래 해안의 위치뿐 아니라 해안 폭과 산림 경계를 원본과 맞출 것.
4. 달구벌 [675,790,48,48], 금성 [723,801,48,48], 대가야 [630,827,48,48]: 성 좌표를 옮기지 말고 바닥 주변 나무·산릉·지류를 수정. 기준 좌표는 각각 (699,814), (747,825), (654,851), native 폭은 24.62,24.62,22. 승인 원본도 구릉/수계에 가까우므로 성 바닥 전체를 별도로 검토.
5. 서쪽 x=600, 남쪽 y=900 경계: 겹침 x=600..654 및 y=900..954를 연결된 동일 지형으로 다시 그릴 것. 흐림/색 덮기로 수로 단절을 숨기지 말 것. detail_2_2만 고치고 인접 원화를 그대로 두면 접합은 끝나지 않는다.

수정 결과는 고정된 native 범위에 직접 정합된 1254×1254 PNG로 제공해야 한다. 원본 무표시 후보를 수정하고 이 검토 UV를 새 그림에 다시 적용하지 말 것. 새 그림은 새 해시로 검증 후 별도 승인한다. 현재 자동 전환 승인은 제주만 유지되며 **남부 신규 승인 범위는 없다**.
