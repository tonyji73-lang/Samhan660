## 영향력·인사·생산

`influence`는 실제 unit_rosters의 국가 병력과 유효 지휘관, 현 소유 도시의 민간 인구와 유효 태수를 조회한다.

`영향력 = 집단 지휘 병력/국가 병력×60 + 집단 태수 도시 민간 인구/국가 민간 인구×40`.

이동 중 부대도 포함하고, 분할·합류로 원장이 중복 집계되지 않는다. 군권 미배정과 유효한 무소속 지휘관을 구분한다. 왕실에 공석을 자동 귀속시키지 않는다. 세금·도시·군수품 소유권이나 국고를 집단에 재분배하지 않는다.

실제632 시작 화면: 전체 병력205,600, 민간 인구1,383,000. 왕실 영향력0, 중앙 연합은 태수 기반235,000으로6.80, 군사 연합은100,000으로2.89였다. 금성 태수를 김춘추→김유신으로 바꾸자 중앙6.80→3.33, 군사2.89→6.36으로 바뀌었다. 김춘추 충성50→40/중앙 협력50→44, 김유신 충성50→58/군사 협력50→54를 실제 화면에서 확인했다.

왕명 반응은 기존 태수 `set_post`와 부대 `appoint`에 연결했다. 같은 인사 반복은 무효, 같은 집단 교체는 개인만 반응한다. 긍정 보상은 인물당6개월에 한 번이고, 지휘관은 전체 실제 지휘 병력이 늘어야 한다. 이동·분할·합류·사망·점령 자동 변경은 왕명 해임으로 처리하지 않는다. 점령 시 자동 태수 변경의 사유를 명시해 기존 기본 사유가 정치 보상으로 오인되는 경로를 수정했다. 연구/생산/훈련 담당자 교체는 정치 보상을 주지 않는다.

인사 견적은 공통 원장의 사본에 같은 반응 함수를 적용하여 **이번에 실제 적용될 전후 충성/협력**을 표시한다. 간격 제한 때문에 보상이 없는 경우에도 일률적으로+8을 약속하지 않는다. 부대 임명과 정치 요구의 후보 검증은 공통 `action_available`을 사용한다.

생산 보정은 `Industry.production_work` 한 곳에서 `능력 작업량 × (0.9 + 협력×0.002)`를 반올림한다. 귀족 생산 담당자만 적용하고, 왕실/무소속/미배정·자격 상실 담당자는 기존 계산을 따른다. 시설 작업량 공유, 잔여100미만, 비용 부족/재료 부족 시 보류, 점령 중단, 국가별 월 중복 방지는 기존 생산 코드를 재사용한다.

## 요구 사건·AI·저장

영향력20 이상, 살아 있는 현지 유효 후보, 실제로 얻을 태수직/군권이 있어야 한다. 야망 가중치2와 현재 불만으로 후보 우선순위를 정하며 높은 충성 인물도 제외하지 않는다. 집단12개월·국가6개월 간격을 요구 발생 시 저장한다. 같은 요구를 거절하거나 다시 불러와 즉시 재발시킬 수 없다.

수락은 기존 임명 API의 반응만 적용한다. 포상은 국가 원장에서100을 고유 영수증 토큰으로 결제하고 충성+5/협력+6, 거절은−6/−6이다. 선택 직전에 후보의 집단·생존·소속·위치·도시 소유권·업무와 비용을 다시 확인한다. 후보 사망/이동/도시 상실로 무효가 된 경우 어느 선택으로도 비용·정치 반응 없이 요구를 닫을 수 있다.

신규 인사 보상 간격을 소모하지 않은 단위 실행에서는 수락+8/+4, 포상+5/+6/금−100, 거절−6/−6을 확인했다. 실제 GUI에서는 앞서 태수·지휘관을 바꾼 **동일 저장**에서 세 선택지를 재실행했다.

A의 획득 보상이0인 이유는 **같은 달 지휘관 획득으로6개월 제한을 이미 사용했기 때문**이다. 김유신의 권한 상실−10/군사 협력−6은 적용된다. 사건 보상을 별도로 더하지 않는다. GUI 사건의 영향력 문턱은 재현성을 위해 기존 신라 부대의 위치/지휘관만 바꾼 fixture로 만들었다. 새 병력·인물·금·장비를 생성하지 않았지만, 이 부분을 정상 이동 플레이로 달성한 결과라고 주장하지 않는다.

AI 왕은 실제 캠페인의 월 사건 경로에서 같은 요구/견적/해결 API를 호출한다. 직무 능력이 낮아지지 않고 결과 집단 영향력60 이하면 수락한다. 그렇지 않으면 `보급 예비금300 + 소유 도시별 기존 난이도 모집 목표의 금 비용`을 남길 때만100 포상하며, 나머지는 거절한다. 현 버전은 보수적인 예산 상한으로 실제 인구/군량 제한에 걸리는 모집 도시까지 예비금을 잡는다.

자연30개월 감사에서는 정치 영향력 문턱을 만족하는 요구가 관찰되지 않았다. 별도의 실제 월 사건 경로 fixture로 세 판단을 실행했다: 높은 적성/분산 →수락, 금11,000(검증용 예산을 명시 지급)/예비금1,500 →포상100, 금1,000/예비금1,500 →거절. 이 예산 fixture는 정상 공급 감사와 완전히 분리했다. [AI 판단 로그](../.godot/noble-results/supplement.json)에 선택·이유·예비금·결과를 남겼다.

저장은 기존 인물 원장 안의 politics와 loyalty/ambition을 보존하므로 별도 중복 장부가 없다. 집단 협력0, 이력, 보상/요구 간격, 대기 요구, 해결 영수증을 반복 복원했다. 불러오기에서는 새 요구 생성이나 AI 결정을 실행하지 않고 이미 저장된 플레이어 대기 선택만 표시한다. 정치 자료 없는 구저장도 기존 자원·부대·인구와 과거 인사를 바꾸지 않고 복원한다.

- `Registry.set_post / Army.appoint / Industry.production_work`: 기존 화면과 다음 기능도 사용하는 실제 변경/산출 경로.
