## 발견·수정·재확인

1. 김춘추의 현재 효과와 선덕여왕 후보 표시가 섞이지 않도록 현재 태수 요약 / 선택 후보 / 임명 시 변화로 분리했다. 후보를 바꾸면 큰 초상·이름·능력과 견적이 함께 바뀐다.
2. 설명 시작 여백, 후보 변경 시 스크롤 초기화, 동일 후보 새로고침 시 위치 보존을 추가했다. 첫 줄부터 읽히고 나머지 정보는 상세 스크롤로 접근한다.
3. 720p 보조 버튼이 하단 탐색과 겹치는 문제를 수정했다. 긴 이름과 두 줄 불가 사유를 넣은 추가 검사에서도 겹침이 발견되어 상세 최소 높이를 72로 줄였다. 충분한 공간에서는 상세 영역이 자동으로 늘어난다. 이름은 한 줄로 제한하고 전체 이름을 툴팁으로 제공한다. 해임 버튼도 가로 확장을 제한한다.
4. 선덕여왕은 기존 고해상도 투명 오버레이를 재사용했다. 다른 인물의 기존 고해상도 사각 초상도 유지했다. 붉은 주 버튼을 높이 72/글자 30으로 강조하고 비활성 상태를 분리했다.

## 시각 항목

- 글꼴: 기존 한글 글꼴 사용. 인물 이름 36, 능력 29, 본문 22, 주 버튼 30 논리 픽셀. 720p에서 주요 정보와 버튼을 읽을 수 있다. 긴 본문은 스크롤하며 긴 이름 전체는 툴팁으로 확인한다.
- 배치: 도시 65% / 업무 35% 유지. 현재 태수 요약 위쪽, 큰 후보 초상 중앙, 상세 아래 후보 목록과 붉은 확정 버튼. 취소/닫기는 하단 탐색 위에 남는다. 3명 초과 후보는 가로 스크롤한다.
- 색: 어두운 프레임, 청동·금색 테두리, 크림 패널, 붉은 주 행동. 후보 선택 한 곳만 금색이며 집단 영향력 증가는 중립색이다.
- 이미지: 제공된 채색 전경을 비율 보존하여 도시 영역에 표시한다. 승인 시안의 새 얼굴 대신 기존 게임 인물 자산을 쓴다. 선덕여왕은 왕관과 얼굴이 보이는 상반신 영역을 사용한다.
- 내용: 현재 태수 김춘추 / 후보 선덕여왕, 정치 98→93(-5), 군주 역할을 구분한다. 현재 세입은 현직 효과이고 후보 세입 예측과 혼용하지 않는다. 실제 임명 후 선덕여왕·세입159로 갱신된 화면을 확인했다.

## 남는 차이

김춘추·김유신은 시안의 대형 투명화 대신 기존 사각 초상이다. 도시 그림·기본 팔레트는 맞췄지만 조각 장식, 목재 결, 금속 광택, 서예 제목은 독립 자산 부족으로 단순화했다. 실제 견적·상태·해임·닫기 기능 때문에 시안보다 정보가 많고 일부 상세는 스크롤한다. 임명 전 세입/수확 예측 API는 없어 값을 만들지 않는다. 금성 외 전경은 미제공 상태다.
