## 비교 근거

- 시각 원본: `dev/hanji_ui_source/samhan660_hanji_ui_v1/reference/domestic_default.png`, `approved_personnel.png` (각 1672×941).
- 구현: `tests/hanji_review/domestic-1280.png`, `personnel-1280.png`, `domestic-1920.png`, `personnel-1920.png`, `domestic-2560.png`.
- 결합 비교: `tests/hanji_review/comparison-domestic.png`, `comparison-personnel.png`. 왼쪽 원본을 1280×720로 정규화하고 오른쪽 같은 크기의 실제 화면을 배치한 2560×720 이미지. 두 원본과 구현을 실제로 열어 비교했다.
- Godot canvas_items 설계 좌표 1920×1080, 출력 1280×720 / 1920×1080 / 2560×1440. CSS/DPR은 네이티브 게임이므로 해당하지 않는다.
- 같은 내정/후보 선택 상태를 비교했다. 원본의 642년 4월 예시 인물·수치와 실제 642년 1월 신라 초기 상태는 의도적으로 다르다. 데이터 정확성을 위해 예시 업무/금액은 넣지 않았다.
- 전체 보기에서 각 주요 영역을 비교한 뒤 1280 원본 크기와 1920 캡처에서 본문/후보 능력/확정/비활성 상태를 확인했다. 이 해상도에서 글자가 읽혀 별도 확대 크롭은 필요하지 않았다.

## 수정과 재검토

1. P1: 초반 브랜드 줄바꿈이 상단 높이를 과도하게 늘려 하단 버튼을 화면 밖으로 밀었다. 브랜드 자동 줄바꿈을 해제했다. 이후 뷰포트 내 확정/취소/닫기/월 버튼 bounds 검사를 추가했고 모든 확인 해상도에서 통과했다.
2. P2: 도시 위치 버튼이 이미지 위쪽에 몰렸다. 양쪽 anchor와 offset을 함께 지정하여 농경지/시장/공방을 각 위치로 배치했다.
3. P2: 초기 후보 초상이 작고 중복 태수 요약/업무 탭이 공간을 차지했다. 인사 상태에서는 두 영역을 숨기고 후보 초상을 245×245 논리 좌표로 확대했다. 최종 `personnel-1280/1920.png` 및 결합 비교로 재검토했다.
4. 저장 복원 후 float 월 값의 나머지 연산 오류를 정수 변환으로 수정했다. 실제 저장/복원 GUI 재검사 통과.

## 다섯 시각 항목

- 글꼴: 기존 SamhanUISans Medium/SemiBold, 본문 24/보조 22/제목 46–52 논리 픽셀. 제목 계층과 읽기 가능한 한글을 확인했다. 원본의 붓글씨와는 다르며 별도 서체 미제공에 따른 재사용 결정이다.
- 간격/배치: 도시/명령 약 55:45, 상단 실제 자원, 하단 단일 현재 위치 강조. 긴 업무/예측은 스크롤하고 실행 버튼과 제한 사유는 고정했다. 인사 후보는 3명 초과 시 가로 스크롤로 접근한다.
- 색상: 따뜻한 한지, 먹색 본문, 붉은 확정/선택선. 영향력은 본문색으로 표현하여 자동으로 이익처럼 보이지 않게 했다. 비활성 버튼과 포커스 테두리 구분.
- 이미지: 제공 도시 원본 비율/알파 보존, 기존 한지 텍스처와 인물 초상 연결 재사용. 시안 전체를 배경으로 붙이지 않았다. 장수의 기존 저해상도 질감과 사각 배경은 자산 자체의 특성이다.
- 내용: 실제 국가/도시/날짜/국고/도시 군량, 담당자/진행 기록, 비용/기간, 개인 충성/집단 협력/영향력을 구분한다. 예시 수치나 존재하지 않는 일감을 만들지 않았다.

## 남는 차이

붓자국/인장/매화/붓글씨 제목은 독립 자산 미제공으로 미재현. 버튼은 읽기 쉬운 붉은 면과 선택 밑줄이다. 도시는 원본의 화면 가장자리까지 번지는 구성보다 여백이 크다. 기존 초상 보존과 실제 빈 업무 상태가 원본의 정보 밀도와 다르게 보인다. 이 차이는 `tests/HANJI_UI_V1.md`에 공개했으며 기능/레이아웃 결함으로 숨기지 않았다.
