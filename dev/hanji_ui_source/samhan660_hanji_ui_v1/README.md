# 삼한660 한지 UI v1 — 디자인 적용 패키지

기준일: 2026-09-28

사용자가 선택한 세 번째 시안, ‘한지 국정 장부’를 기준으로 한다. 따뜻한 한지 바탕, 먹으로 그린 도시, 큰 인물 초상, 붉은 인장과 얇은 구분선을 공통 표현으로 사용한다.

## 이번에 준비한 것

- reference/approved_personnel.png: 사용자가 선택한 세 번째 시안 원본. 태수 임명 화면의 시각 기준.
- reference/domestic_default.png: 같은 스타일로 구체화한 내정 기본 화면. 태수 요약, 내정 업무, 담당자 선택과 개발 지시를 보여준다.
- assets/seorabeol_city_ink_concept_v1.png: 글자·버튼·수치를 제거한 도시 일러스트. 배경에 합성할 수 있는 투명 PNG.
- DESIGN_SPEC.md: 화면 구조, 데이터 표시, 상호작용, 자산 사용과 검수 기준.
- VS_CODE_TASK.md: 현재 Godot 프로젝트에서 시작할 구현 작업 지시서.

이 ZIP은 디자인 자료와 구현 지시서이며, 실행 가능한 Godot 프로젝트가 아니다. 이번 작업에서 게임 저장소의 코드 수정·연동·실행 검증은 수행하지 않았다.

## 바로 시작하는 방법

1. 이 패키지를 압축 해제한다.
2. 실제 작업 중인 삼한660 프로젝트를 VS Code에서 연다.
3. VS_CODE_TASK.md 내용을 작업 요청으로 전달하고 이 폴더를 함께 제공한다.
4. 첫 적용 범위는 도시 내정 기본 화면과 태수 임명 흐름이다.

## 해석할 때 주의할 점

시안의 인물 배치, 능력, 소속 집단, 비용, 세입, 충성·영향력 변화량은 화면 설명을 위한 예시다. 실제 게임의 초기 배치나 새로운 밸런스 규칙으로 채택하지 않는다. 현재 장수·도시·업무·정치 시스템에서 값을 읽어 표시한다.

PNG 화면 전체를 게임 배경으로 붙여 버튼만 덧씌우지 않는다. 글자, 수치, 진행 막대, 초상 선택, 버튼, 오류 안내는 실제 UI로 구현한다. 화면 속 장수 그림은 참고용이며 실제 게임에서는 기존 장수 초상 연결을 재사용한다.

도시 그림은 승인된 분위기를 바탕으로 만든 콘셉트 자산이다. 7세기 서라벌의 고증이 완료된 복원도나 승인된 전략 지도의 대체물로 취급하지 않는다.

## 첫 구현의 완료 상태

도시 선택 → 내정 열기 → 담당자 선택 → 현재 규칙으로 개발 접수 → 월 진행 → 결과 갱신, 그리고 태수 변경 → 후보 비교 → 임명 → 관련 수치 갱신이 실제 게임 상태와 연결되어야 한다. 확인 방법은 DESIGN_SPEC.md와 VS_CODE_TASK.md를 따른다.
