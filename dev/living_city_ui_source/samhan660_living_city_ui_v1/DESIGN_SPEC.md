# 삼한660 살아 있는 도시 UI v1 — 적용 기준

## 1. 범위와 근거

시각 기준은 reference/approved_personnel.png, 내정 기본 상태의 기준은 reference/domestic_default.png다. 최종 선택은 첫 번째 ‘살아 있는 도시’ 시안이다. 두 이미지의 넓은 채색 도시, 오른쪽 밝은 업무 패널, 어두운 목재·금속 장식과 초상 중심의 인사를 유지한다.

이번 지시서는 사용자가 공유한 구현 보고서와 선택한 시안을 근거로 작성했다. 현재 저장소의 실제 파일·함수·장면 구조를 직접 검사한 설계는 아니다. 연결 지점과 계산 규칙은 구현 전에 현재 프로젝트에서 확인한다.

첫 범위: 도시 내정 기본 화면, 기존 내정 담당자 선택, 태수 후보 선택·임명, 결과 갱신. 조정·외교·군수 전체 개편과 새로운 정치·경제 규칙은 후속 범위다.

## 2. 화면 구성

| 영역 | 구성 | 적용 기준 |
| --- | --- | --- |
| 상단 | 국가·도시·시나리오 날짜·국고·도시 군량 | 국가 소유와 도시 소유를 글자로 구분한다. |
| 왼쪽 약 65% | 도시 이름, 도시 그림, 진행 업무, 도시 현황 | 도시 문맥을 유지하고 오른쪽 작업 영역만 전환한다. |
| 오른쪽 약 35% | 내정 명령 또는 태수 임명 | 내정 기본 화면에서 태수 변경을 누르면 후보 선택으로 전환한다. |
| 하단 | 현재 기능 탐색, 다음 달 | 실제 현재 위치 하나만 선택 표시한다. |

1920×1080을 배치 검토 기준으로 삼되, 이미지 자체의 픽셀 크기를 UI 좌표로 하드코딩하지 않는다. 현재 프로젝트의 화면 배율 설정에 맞춰 컨테이너와 여백으로 배치한다. 도시 그림과 초상은 비율을 보존한다.

1280×720에서 본문과 주요 버튼이 읽혀야 한다. 공간이 부족하면 설명문과 진행 목록을 스크롤하고 확정 버튼·비용·불가 사유를 화면 안에 유지한다. 2560×1440에서도 인물이나 도시 그림을 비율 없이 늘리지 않는다.

## 3. 시각 언어

- 도시 영역: 깊이감 있는 채색 도시를 크게 보여준다. 농경지·시장·공방을 서로 구분할 수 있게 배치한다.
- 상하단: 어두운 목재·칠기 느낌과 절제된 청동·금색 장식으로 국가 운영 화면의 무게감을 만든다.
- 오른쪽 업무 영역: 따뜻한 크림색 종이 바탕을 사용하며, 본문 뒤 무늬는 약하게 둔다.
- 제목: 오른쪽은 짙은 먹색, 어두운 상하단은 밝은 글자로 대비를 확보한다. 본문·수치는 읽기 쉬운 한글 글꼴을 사용한다.
- 인물: 기존 게임 초상과 인물 식별자를 사용한다. 새 시안의 얼굴로 기존 장수 자산을 덮어쓰지 않는다.
- 선택: 탭·후보·현재 메뉴에는 금색 강조와 테두리 또는 밑줄을 사용한다. 색뿐 아니라 선택 표시와 문구도 제공한다.
- 확정: 오른쪽 아래 붉은 주 버튼으로 개발 지시·임명을 실행한다. 취소와 후보 선택은 시각적 강도를 낮춘다.
- 구분: 여백과 얇은 선을 우선하고, 작은 테두리 상자를 반복하지 않는다.
- 색의 의미: 비용·부족·정지·완료를 구분한다. 귀족 영향력 증가는 무조건 좋은 결과로 녹색 처리하지 않는다. 개인 충성, 집단 협력, 영향력은 서로 다른 개념으로 표시한다.
- 하단은 현재 위치 하나만 강조한다. 도시 내정 안에서 태수를 바꾸는 동안에도 현재 도시와 상단 자원 정보는 유지한다.

## 4. 내정 기본 화면

왼쪽 도시 그림의 농경지·시장·공방은 장식 이미지와 별도 조작 요소로 둔다. 클릭 위치와 선택 강조는 화면 배율을 따라야 한다. 같은 기능으로 가는 텍스트 메뉴도 제공한다.

진행 업무 목록에는 업무명, 담당자, 진행 상태, 완료 예상 또는 중단 이유를 표시한다. 담당자가 없는 작업·현재 구현에 없는 항목을 시안을 채우기 위해 만들지 않는다.

오른쪽 35% 안에서도 초상과 확정 영역이 설명문에 밀려 사라지지 않게 한다. 낮은 해상도에서는 장식과 초상 높이를 먼저 줄이고 명령 정보는 읽을 수 있게 유지한다.

오른쪽 위에는 태수의 이름·초상·실제 관련 능력·현재 효과를 보여주고 태수 변경으로 연결한다. 공석이면 공석 상태와 임명 진입을 보여준다.

농업·상업·건설 등은 현재 프로젝트에 있는 기능만 연결한다. 기존 기능의 진입점을 잃지 않도록, 첫 범위 밖의 메뉴는 기존 화면으로 연결한다.

업무 선택 → 담당자 선택 → 비용·기간·가능 여부 확인 → 개발 지시 순서로 진행한다. 비용 접수와 업무 생성은 기존 명령을 호출한다. 이미 진행 중인 같은 업무, 자금 부족, 담당자 충돌은 현재 규칙에 따라 버튼과 사유에 반영한다.

## 5. 담당자 선택과 태수 임명

| 표시 | 데이터 기준 |
| --- | --- |
| 이름·초상·생존·국가·소속 | 현재 인물 레지스트리와 시나리오 상태 |
| 관련 능력·특기 | 현재 업무 계산에 실제 사용되는 항목 |
| 위치·직책·진행 업무 | 현재 인물·도시·업무 상태 |
| 충성 | 개인 충성 값과 현재 변화 사유 |
| 협력 | 정치집단의 협력 값과 변화 사유 |
| 영향력 | 현재 정치 시스템이 계산한 영향력 및 근거 |
| 실행 가능 여부 | 기존 검증·견적·임명 함수의 판정 |

후보 세 명은 시안의 표현 예시다. 실제 후보 수가 많으면 목록 또는 가로 스크롤로 모두 접근할 수 있어야 한다. 후보가 없을 때도 화면이 정상적으로 닫혀야 한다.

농업 담당자 선택과 태수 임명은 다른 행동이다. 후보 선택 요소는 공통으로 사용할 수 있지만 권한·기간·비용·직책 변화는 각 기능의 기존 규칙을 따른다.

태수 후보를 고르면 임명 전후의 효과, 기존 업무에 미치는 영향, 이동 또는 지연 조건을 확인한다. 효과 수치는 기존 계산을 재사용할 때만 정확한 값으로 표시한다. UI에 별도 계산식이나 예시 값을 넣어 맞추지 않는다. 계산 근거가 없는 예상 효과는 알려진 설명과 실제 제한을 표시하고 미연결 항목으로 보고한다.

후보 선택만으로 금·업무·충성·소속을 변경하지 않는다. 확정 시 한 번만 변경하고 성공 후 실제 상태를 다시 읽는다. 취소하면 선택 전 상태와 도시 문맥으로 돌아간다.

## 6. 자산 적용

assets/seorabeol_city_panorama_concept_v1.png는 도시 전경용이다. 화면 전체의 배경, 실제 지도, 클릭 판정 마스크로 사용하지 않는다. 이 파일은 불투명한 직사각형 전경이다. 도시 영역에 비율을 보존해 맞추고 필요한 경우 가장자리만 자른다. 주요 농경지·시장·공방과 성곽이 과도하게 잘리지 않도록 기준점을 확인한다. 해상도는 ASSET_INFO.md를 참고한다.

그림 위 농경지·시장·공방 이름과 클릭 영역은 실제 UI로 올린다. 현재 프로젝트의 목재·금속 테두리·종이·아이콘 자산을 먼저 재사용한다. 공통 테마로 글꼴·색·여백·선택 상태를 정리한다. 이번 패키지에는 별도의 목재·금속·종이 텍스처, 버튼 스프라이트 또는 장수 초상 제작본이 포함되어 있지 않다.

서라벌 그림을 모든 도시에 그대로 반복하는 것은 전국 최종 디자인이 아니다. 첫 대표 화면 적용 후 도시별 배경의 연결 방식을 정한다. 이미 승인된 전략 지도와 35개 거점 위치는 이 내정 그림으로 교체하지 않는다.

## 7. 입력과 갱신

- 버튼 연속 입력으로 비용이나 임명이 중복 처리되지 않아야 한다.
- 닫기·Esc·도시 전환 후 지도 입력과 선택 상태가 정상 복구되어야 한다.
- 확인 과정 중 월 진행·다른 팝업·도시 전환 충돌은 현재 게임의 잠금 규칙을 따른다.
- 창을 다시 열 때 오래된 후보, 비용, 진행 상황을 남기지 않는다.
- 저장·복원 후에도 실제 업무와 담당자, 국고, 도시 재고, 정치 값이 일치해야 한다.
- 접근 가능한 키보드 포커스 순서와 활성·비활성 버튼의 구분을 제공한다.

## 8. 완료 확인

642년 신라의 정상 상태에서 내정 화면을 열고 현재 값과 UI를 대조한다. 실제로 가능한 담당자를 선택하여 개발 접수, 월 완료, 태수 변경, 저장·복원을 확인한다. 테스트를 위해 비용·장수 능력·인사 제한을 바꾸지 않는다.

추가로 공석, 담당자 업무 중복, 금 부족, 후보 없음, 취소, 반복 확정, 반복 열기·닫기를 확인한다. 기존 테스트는 영향을 받은 기능을 중심으로 실행한다. 검수에서 발견한 범위 밖의 문제는 별도로 기록한다.

동일 상태의 구현 전·후 화면과 적용 후 1280×720 및 1920×1080 화면을 남긴다. 선택한 1번 시안과 비교할 때 도시 65%·업무 35%의 비중, 큰 초상, 상하단의 어두운 장식, 판단 정보와 붉은 확정 버튼을 확인한다. 실행하거나 보지 못한 항목은 미검증으로 명시한다.
