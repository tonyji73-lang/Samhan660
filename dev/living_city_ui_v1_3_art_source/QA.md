# 자산 패키지 검수

작성: 2026-09-29. 이 문서는 이곳에서 실제 수행한 항목만 기록한다.

- PNG 6개: 모두 RGBA, 바깥 투명 픽셀 존재, 원본과 SHA-256/바이트 일치.
- 속이 빈 업무 패널·후보 카드·도시 제목: 중앙 50% 영역 알파가 8/255 이하인지 검사. 정확한 알파 최댓값은 manifest에 기록.
- 원본 영역 6개: 이미지 범위 안에 있고, alpha>8 장식 전체와 4px 안전 여백을 포함함.
- 논리 텍스처·9분할 10개 프로필: 분할 폭/높이의 합이 텍스처 및 표시 예 크기보다 작음.
- 폰트 2개: 파일 메타데이터·버전·원문 OFL 포함 확인. 삼한660, 금성, 내정, 태수 임명, 농업 개발, 담당자 선택, 필요 금, 완료 예정, 예상 성과, 선덕여왕, 김춘추, 김유신, 신라, 백제, 고구려 표본 글리프 포함.
- 버튼 텍스트·게임 수치는 PNG에 굽지 않음. 시각 확인으로 텍스트 없는 장식임을 점검.

HTML의 상대경로와 JavaScript 구문을 검사했다. 브라우저 실행기가 설치되어 있지 않았으며 추가 다운로드도 정상 ZIP을 반환하지 않아 실제 브라우저 렌더링·버튼 조작은 확인하지 못했다. CSS/Canvas 미리보기는 Godot 게임 실행이 아니다. 원본 PNG 자체는 이미지 도구로 열어 확인했다.

## 이곳에서 수행하지 않은 항목

사용자 Windows worktree 수정, Godot 예제 파싱/실행, 실제 화면의 클릭/스크롤/저장/국고/임명/월 처리, 내정 회귀, 게임 내보내기. 기존 167개·131개 같은 검사 결과를 이번 결과로 주장하지 않는다.
