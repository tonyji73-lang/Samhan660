# 이미지 정보

생성된 원본 이미지를 수정하지 않고 패키지에 복사했다. 아래는 실제 파일 검사 결과다.

| 파일 | 실제 크기 | 색상 모드 | 알파 채널 |
| --- | --- | --- | --- |
| reference/approved_personnel.png | 1672×941 | RGB | 없음 |
| reference/domestic_default.png | 1672×941 | RGB | 없음 |
| assets/seorabeol_city_panorama_concept_v1.png | 1448×1086 | RGB | 없음 |

approved_personnel.png는 사용자가 최종 선택한 1번 원본이다. domestic_default.png는 그 스타일에 맞춘 내정 기본 화면이다. 두 화면의 인물·수치·문구는 레이아웃 참고용이며 실제 UI에는 기존 게임의 데이터를 연결한다.

도시 전경은 글자·메뉴가 없는 불투명 RGB 이미지다. 왼쪽 도시 영역에서 비율을 보존하고 배율별 잘림을 확인한다. 투명 잉크화 자산으로 처리하지 않는다. 건물 배치와 풍경은 콘셉트이며 고증이 완료된 역사 복원도가 아니다.

장수 초상·목재·금속·종이 텍스처·버튼 스프라이트의 별도 제작본은 포함하지 않는다. 게임의 기존 자산을 먼저 재사용한다.
