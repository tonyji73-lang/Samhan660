# 삼한660 Living City UI V1.1 — 후속 수정 패키지

기준일: 2026-09-28. 최종 디자인은 1번 ‘살아 있는 도시’다.

현재 프로젝트에 Living City UI V1이 적용됐다는 사용자 보고와 실제 캡처 두 장을 바탕으로 만든 후속 작업 자료다. 기존 구현 위에서 태수 임명 화면을 정리하고, 내정 기본 화면까지 실제 실행과 시각 비교로 확인한다.

## 시작 방법

1. 이 ZIP을 별도 자료 폴더에 압축 해제한다.
2. 실제 작업 중인 Godot 프로젝트를 연 VS Code에 이 폴더와 VS_CODE_TASK.md를 전달한다.
3. VS_CODE_TASK.md 순서대로 구현·실행·비교를 진행한다. 프로젝트 관례에 따라 변경 보고서와 캡처를 남긴다.

이 ZIP은 디자인·검수·작업 지시 자료다. 실행 가능한 게임 프로젝트나 코드 패치가 아니며, 이 패키지 제작 과정에서 사용자의 Windows 프로젝트를 수정하거나 Godot를 실행하지 않았다. 기존 V1 적용 패키지의 후속 버전이다.

## 작업 순서

1. 현재 태수 / 선택 후보 / 임명 시 변화를 구분한다.
2. 설명문 잘림과 스크롤 배치를 수정한다.
3. 기존 초상의 존재감과 확정 버튼을 강화한다.
4. 내정 기본 화면과 담당자 선택도 같은 기준으로 확인·수정한다.
5. 같은 게임 상태의 전후 캡처를 비교하고, 기존 기능과 저장·입력 복구를 확인한다.

## 파일

- VS_CODE_TASK.md: 바로 전달할 후속 작업 요청.
- AUDIT_NOTES.md: 캡처에서 확인된 점과 아직 확인하지 못한 점.
- DESIGN_SPEC.md: 1번 디자인의 공통 기준과 V1.1 보완 사항.
- ASSET_INFO.md: 이미지 종류와 실제 크기.
- reference/approved_personnel.png: 사용자가 선택한 1번 태수 임명 시안.
- reference/domestic_default.png: 같은 스타일의 내정 기본 시안.
- observed/01-map-city.png: 사용자가 제공한 지도·도시 선택 화면.
- observed/02-governor-selection.png: 사용자가 제공한 V1 태수 임명 화면.
- assets/seorabeol_city_panorama_concept_v1.png: 기존 V1과 같은 불투명 도시 전경.

시안의 인물·연도·능력·국고·보너스·정치 변화량은 예시다. 실제 게임 데이터와 기존 인물 초상 연결을 유지한다. 도시 그림은 콘셉트이며 역사 복원도나 승인된 전략 지도의 대체물이 아니다.
