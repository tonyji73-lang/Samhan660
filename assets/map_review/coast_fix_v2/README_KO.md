# 삼한660 첫 구역 — 해안 보정 v2

첫 구역 `c03_r02`의 금관가야·소가야·울릉 주변 지형을 보정했습니다. 게임 좌표와 코드는 바꾸지 않았습니다. 기본 이미지 생성 도구로 국소 편집을 두 차례 수행했으며, 생성 결과를 임의 확대하지 않은 PNG 원본으로 제공합니다.

## 결과

- 금관가야·소가야: 고정된 도시 앵커가 남쪽 해상에 놓이던 문제를 지형 아트에서 보정하고, 연결된 육지와 평지를 확보했습니다.
- 울릉: 지정 좌표를 포함하도록 섬의 위치를 보정했습니다.
- 세 앵커의 지면을 전후 대조 그림에서 확인하고, 별도 성 이미지를 올린 브라우저 시연에서도 위치를 확인했습니다.
- 브라우저 시연의 보정 전후 전환에서 도시 화면 좌표는 동일했습니다. 최대 3배 화면의 역변환 좌표 오차는 1.2e-16 이내였습니다. 1배·3배, 실제 마우스 휠, 도시 선택, 성 표시, 360px 화면을 확인했습니다.
- 게임의 54개 도시·지역 좌표 사본은 첫 묶음과 바이트 단위로 동일합니다.

이 결과는 **첫 구역의 세 지점 아트 보정 및 브라우저 시연 검증**입니다. 실제 게임 구현, 정확한 역사 지형 복원, 전체 24구역 완성 또는 Godot 검증을 뜻하지 않습니다.

## 다음: Godot에 첫 구역 비교 화면 연결

1. 논리 지도 6144×4096에서 위치 `(3072,2048)`, 크기 `(1024,1024)`에 이 텍스처를 놓습니다. 실제 텍스처 픽셀 수와 세계 좌표 크기는 구분합니다.
2. 도시·경로·지도 이미지는 같은 변환을 사용합니다. 도시 UV는 런타임의 기존 데이터가 기준입니다.
3. 낮은 확대 단계에서도 **보정된 해안선이 같은 위치에 남도록** 해야 합니다. 보정 전 전체 지도와 보정 후 상세 지형을 확대 단계에 따라 번갈아 쓰면 새 땅이나 섬이 갑자기 나타납니다. 비교용 모드에서는 이 구역을 모든 확대 단계에서 동일하게 유지하고, 전체 지도와 상세 구역 사이의 연결 문제를 확인합니다.
4. 기존 영토 마스크와 보정된 육지를 함께 대조합니다. 시각 지형 보정만으로 클릭 영역·영토 표현까지 맞았다고 취급하지 않습니다.
5. 실제 게임의 1280×720·1920×1080에서 성 크기·앵커·선택·확대·이동을 확인하고, 검수가 끝난 구역부터 채택합니다.

## 남은 검토

- 첫 구역의 나머지 13개 앵커와 지형 가독성은 이번 세 지점처럼 개별 재검수하지 않았습니다.
- 인접 구역과의 해안선·색·조명 연결은 미완료입니다. 편집 전후 바깥 60px 띠의 평균 RGB 절대 차이는 약 11.79/255로, 가장자리 픽셀이 완전히 보존된 것은 아닙니다. 이 수치는 접합 품질 통과 기준이 아닙니다.
- 전체 지도 축소 화면과 기존 영토 마스크의 정합은 Godot에서 확인해야 합니다. 현재 브라우저 시연은 첫 구역만 다룹니다.
- 원본 1254px는 최종 목표 2048px보다 작습니다. 최대 확대에서 선명도가 부족하면 해당 구역의 실제 상세 원본을 더 제작해야 합니다.
- 이번 성 한 종류는 배치 확인용이며, 울릉을 포함한 지역별 실제 건축 고증이 완료된 자산이 아닙니다.
