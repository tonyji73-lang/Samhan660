# 동해안 상세 지형 시안 v1

이전 `Samhan660_Korea_Terrain_Draft_v1.zip`과 다른 **새 지형 자산**입니다.
실직·금성·울릉 주변을 새로 그렸으며, 기존 성 좌표와 성 원본을 기준으로
넓은 마른 부지를 확보하는 방향으로 수정했습니다.

- 새 원본: `art/terrain_east_coast_detail_draft_v1_1254.png` — 1254×1254 PNG.
- 범위: 월드 (3584, 2048)에서 512×512. 한국 전체가 아닌 동해안 일부입니다.
- 적용 좌표: `data/detail_registration.json`.
- 성 배치 비교: `review/THREE_SITE_REGISTRATION.png`.
- 주변과의 접합 비교: `review/PARENT_JOIN_REVIEW.png`.

성은 게임에서 별도로 표시하므로 지형 PNG에는 성·지명·버튼이 없습니다.
리뷰 이미지에 표시한 성은 제공받은 원본을 계산된 좌표에 그린 정적 검토입니다.
이 환경에서 Godot를 실행한 결과가 아닙니다.

## 현재 상태

새 상세 자산 제작과 좌표 계산은 완료했습니다. 세 성의 기존 좌표를 유지했고,
기준 폭 130 월드 단위에서 성을 겹쳐 검토했습니다. 완전한 성 바닥 정합으로
판정하지 않았으며 울릉 북서쪽 해안의 여유, 낮은 배율에서 성의 최소 크기,
실제 게임 표시를 확인해야 합니다.

상세 그림의 해안과 강을 수정했으므로 기존 축소 지도와 지형이 정확히 일치하지
않습니다. 네 변 접합도 완료되지 않았습니다. 기존 지도 위에 사각형을 얹은 것을
완성으로 보고하면 안 됩니다. 현재 게임 기본 지도의 완성 교체본이 아닙니다.
기존 마스크 미할당 9곳, 35곳 전체 성 바닥, 세계 지도 접합은 별도 남은 작업입니다.

## 사용

1. ZIP을 압축 해제합니다.
2. `CODEX_READ_FIRST.txt` 내용을 VS Code Codex 채팅에 붙여넣고 압축 푼 폴더를 알려주세요.
3. 현재 `한국 시안`에서 실제 성과 확대·축소 상태로 검토합니다.

`CODEX_READ_FIRST.txt`는 실행 프로그램이 아니라 Codex에 전달하는 작업 요청문입니다.
기존 게임 코드와 저장 파일은 이 ZIP에 포함하지 않았습니다.
