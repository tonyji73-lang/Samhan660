3. 실제 메뉴 경로
- 목표: 우측 상단 Menu → 캠페인 목표·전쟁 준비.
- 도시: 지도에서 도시 클릭 → 상세. 장수·도시 군량을 확인합니다.
- 태수/지휘관: Menu → 귀족·군권·인사정치 → 대상 도시/부대와 인물 → 견적 확인 후 인사 실행.
- 인계: Menu → 권력 인계·차질 현황. 보상·기한·강제의 비용과 인계 시점을 먼저 읽으세요.
- 농업: 도시 → 내정 → 담당자 → 개발 업무 시작. 비용은 즉시, 성과는 다음 월입니다.
- 군수: 도시 → 생산 → 건설·연구 업무 관리. 수행 도시·시설/연구·담당자를 고른 뒤 접수합니다.
- 철: 생산 품목의 철 공급과 철 조달·정련(공통)은 비용·지역 조건이 다릅니다. 기본 제련은 이미 연구된 새 게임도 있습니다.
- 부대: 도시 → 징병 → 부대 편성·장비 지급·훈련. 무기1묶음은 보병100명분입니다.
- 수송: 도시 → 이동 → 육상 군량·철·칼 수송 (장수/병력 불필요). 병력/장수를 반드시 선택할 필요는 없습니다.
- 출진: 도시 카드의 출진, 또는 군사 화면의 도시 가용 부대 출정 → 적 도시 선택 → 출진.
- 월 진행: 상단 턴 종료. 사건 선택이 나오면 결과·비용을 읽고 선택합니다.
- 저장: 상단 저장. 내 진행은 campaign_save_35_regions_v1.json에 저장됩니다.
- 복원: 상단 불러오기는 내 진행, Menu → 저장 파일 선택은 샘플 등 다른 저장을 선택합니다.

4. 명령이 막혔을 때
국가 국고와 선택 도시 군량은 다릅니다. 다른 도시 창고나 수송 중 물자를 바로 사용할 수 없습니다.
담당자의 소속·위치·이동·현재 업무, 시설/기술 조건, 모집 인구·동원 여력, 출정 지휘 차질을 확인하세요.
회색 버튼 주변 견적에 사유가 나옵니다. 연구가 이미 최고 단계라면 다시 결제할 필요가 없습니다.
훈련·인계 기간은 담당자와 현재 조건이 유지될 때의 예상입니다. 닫기/Esc 후 지도를 다시 조작할 수 있습니다.
