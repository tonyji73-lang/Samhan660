# 검증 범위

## 확인한 것

- 첨부 원본 ZIP의 중앙 목록과 전체 CRC: 정상.
- 승인 원본 크롭은 지도 [560,740,300,260]에서 추출했고 해당 원본의 SHA를 JSON에 기록했다.
- 보정 PNG 디코딩, 실제 크기 1346×1168, SHA 기록.
- 이미지 생성 도구로 지형을 재작성하고 세 성 공터를 추가 수정했다. 승인 크롭의 비교용 확대를 결과물로 제공한 것이 아니다.
- 네 타일이 맞닿는 영역을 한 텍스처로 작성했다. 내부 x=600 및 y=900에서 별도 파일을 교체할 필요가 없다.
- 고정 좌표·피벗·폭으로 원본 성 PNG를 합성한 정적 진단을 확인했다. 달구벌·금성의 공터와 대가야 강둑 주변을 점검했다. 성 바닥 전체 통과 판정과 다르다.

## 미완료 / 실제 적용 시 확인

- 원본과 해안·물길의 픽셀 단위 동일성은 보장하지 않는다. 섬 윤곽과 좁은 수로의 세부 차이는 게임에서 다시 대조해야 한다.
- 대가야의 고정 성 바닥에 육지를 확보하려고 주변 강둑과 짧은 물길을 국소 변경했다. 따라서 이 부분은 승인 원본과 동일한 지리라고 주장하지 않는다. 합류점·분기 연결을 원본과 대조하고, 전체 성 하부와 함께 실제 게임에서 확인해야 한다.
- 패치 바깥 테두리와 기존 지형 사이의 색·지형 연결은 미검증이다. 내부 타일 접합 해결과 별개다.
- PNG의 실질 밀도는 약 4.49배다. 최대 줌12에서 모든 해상도가 선명하다는 보장이 아니다.
- Godot 연결·GUI 입력·자동 LOD·저장 복원·성 선택은 이 환경에서 실행하지 않았다. 첨부한 정적 비교판은 실제 게임 캡처가 아니다.
- HTML 미리보기는 제작했으나 로컬 브라우저 실행 검증은 환경상 완료하지 못했다. 정적 비교판은 별도 SVG 렌더러로 생성·확인했다.
- 전 지역 정합, 35개 성 바닥, 영토 마스크9곳, 세계 접합은 이번 남부 패치로 완료되지 않는다.
