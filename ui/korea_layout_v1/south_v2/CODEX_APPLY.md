# VS Code Codex 적용 요청

현재 미커밋 작업과 제주 자동 LOD를 보존하면서 이 폴더의 남부 보정 PNG를 실제 비교 화면에 연결해줘.

1. `assets/south_continuous_v2.png`와 `south_continuous_v2.json`을 별도 남부 보정 폴더에 추가해. 기존 13장 및 제주 파일을 덮어쓰지 마.
2. 이 파일은 1346×1168 PNG 한 장이며 승인 지도 `[560,740,300,260]`에 대응한다. 기존 detail_2_2 전체에 늘려 넣지 말고 동일 지도 카메라를 사용하는 지역 패치로 연결해. x=600과 y=900 안쪽에서는 이 텍스처를 연속으로 사용해. 네 타일의 교차 범위와 UV는 JSON에 있다.
3. 기존 후보에만 맞는 12개 대응점 UV 메시를 새 PNG에 적용하지 마. 새 범위의 항등 UV로 먼저 비교하고, 어긋난 위치가 있으면 새 원화에 대한 대응점을 측정해.
4. 지원 경로와 성은 새 지형 위에 기존 좌표로 그려. 달구벌·금성·대가야의 좌표·크기·피벗을 유지하고 전체 바닥을 확인해. 대가야 성 아래 물 겹침을 줄이려고 원화의 강둑과 짧은 물길을 국소 변경했다. 이 부분의 합류점·분기 연결이 승인 원본과 달라지는지 특히 확인해. 자동 정합 승인 자료로 취급하지 마.
5. 하구의 섬 개수/연결 수로, 동해안 곶, 패치 외곽 x=560/860 및 y=740/1000에서 원본과의 접합을 실제 비교해. 한 장 내부의 이전 타일 접합이 없어졌다는 사실을 외곽 정합 완료로 혼동하지 마. 넓은 흐림으로 지리 차이를 가리지 마.
6. 같은 위치·배율로 1280×720,1920×1080 전후 캡처를 남겨. 줌 왕복·경계 이동·세 성 선택·지원 경로를 확인하고, 통과한 영역만 새 이미지 해시에 묶어서 자동 전환을 승인해. 제주 자동 전환을 유지해.
7. 새 플레이용 비교 버튼을 만들지 말고 기존 개발 검토 경로를 활용해. 기존 게임 규칙·저장·세력 선택 UI·초상·선언문을 보존해. 관련 없는 전체 회귀는 반복하지 마.

결과는 연결한 실제 범위, 같은 카메라의 실제 게임 캡처, 남은 어긋남으로 보고해. 이 패키지를 열거나 이미지 로드에 성공한 것만으로 게임 정합 완료라고 보고하지 마.
