# Samhan660 — 전 지역 R3 스타일 지형 자산

이 패키지는 실제 신규 지형 PNG 13장과 배치 정보를 담는다. 자동 설치본이나 게임 적용 완료본은 아니다. 최신 로컬 프로젝트를 기준으로 아래 작업을 진행한다.

## 적용 목표

밝은 아틀라스 플레이 화면을 새 캠페인과 저장 불러오기의 기본 화면으로 통일한다. 기존 전체 지도·시안·후보·r2/r3 비교 버튼은 플레이 UI에서 정리한다. 전체 지도는 같은 화면의 축소 기능으로 제공한다. 공유 게임 로직이나 기존 지형 자료는 참조를 확인하기 전에 삭제하지 않는다.

## 자산 연결

1. 이 폴더를 프로젝트의 `ui/korea_layout_v1/full_r3_v1/`에 추가한다. 기존 승인 지도와 r3 파일을 덮어쓰지 않는다.
2. `manifest.json`의 `source_rect_px`는 승인 지도 1254×1254의 [x,y,width,height]이다. 모든 타일은 같은 지도 카메라 변환을 공유한다. PNG 자체 해상도를 세계 좌표로 사용하지 않는다.
3. `assets/overview` 4장은 넓은 범위, `assets/detail` 9장은 근접 범위다. 근접 타일의 사각 범위 안에 기존 35개 거점이 모두 포함된다. `castle_tile_links.json`의 local_uv는 산술 배치 정보이며, 성 바닥이나 새 지형과의 시각적 정합이 검증되었다는 뜻은 아니다.
4. 신규 PNG는 독립 생성된 후보다. 같은 좌표를 넣어도 해안·강·숲이 정확히 일치하지 않을 수 있다. 기준점으로 해안과 수계를 맞추고 겹침 영역의 색·연속성을 보정한다. 넓은 흐림 혼합만으로 잘못된 지형을 숨기지 않는다.
5. 지리 정합을 통과한 구역부터 같은 화면의 배율에 따른 상세 전환을 연결한다. 화면상 원본 1픽셀의 크기와 타일 texel 밀도를 비교한다. 근접 밀도는 manifest에 기록되어 있다. 무제한 확대를 허용하거나 PNG를 단순 확대해서 해결됐다고 보고하지 않는다.
6. 기존 중앙·동해 r3와 신규 타일이 겹치는 곳은 동시 중복 렌더링하지 않도록 우선순위를 명시한다. 승인 r3도 남은 정합 문제가 있었으므로 무조건 기준 지형으로 덮어쓰지 않는다. 승인 원본 좌표가 기준이다.

## 보존 및 확인

- 성 좌표·클릭 판정·지원 경로·영토 데이터·게임 규칙·사용자 저장·세력 선택 UI·초상·선언문을 보존한다.
- 1280×720과 1920×1080에서 모든 35개 거점의 최대 지원 배율, 경계 왕복 이동, 줌 왕복, 성 선택과 경로 위치를 실제 확인한다.
- 실제 시작과 저장 불러오기에서 새 플레이 화면이 바로 열리는지 확인한다.
- 이미지 단순 로드나 자동 검사 건수만으로 선명도·정합 완료를 판정하지 않는다. 북부/중부/남부/제주의 동일 위치 전후 캡처를 제공한다.
- 불일치가 있는 구역은 위치와 범위를 기록한다. 이 패키지의 production_ready=false를 확인 없이 true로 바꾸지 않는다.

## 사용자에게 보고

실제 수정 파일, 새 기본 플레이 화면 진입 결과, 연결한 타일 수, 미완료 접합·성 바닥, 원본 대비 동일 배율 캡처를 간결하게 보고한다. 이 ZIP만 받은 상태를 게임 반영 완료로 표현하지 않는다.
