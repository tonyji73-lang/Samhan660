# 검증 범위 — 2026-09-23

- 신규 PNG 13장 디코딩 및 크기 확인, SHA-256 기록 완료.
- 실제 출력은 전부 1254×1254. 4K/8K 원본으로 표현하지 않음.
- 넓은 구역: 원본 704×704 → 1254×1254, 선형 밀도 약 1.78배.
- 근접 구역: 원본 354×354 → 1254×1254, 선형 밀도 약 3.54배.
- 35개 거점 모두 근접 구역 사각 범위 안에 들어감. 이는 성 바닥이 지형과 맞는다는 검증이 아님.
- 화면 이미지상 나무·바위·강둑의 선명도는 개선됨. 지형은 생성된 묘사이며 실제 지리 조사 자료가 아님.
- 독립 생성으로 강 분기, 해안 굴곡, 섬 크기와 색이 달라질 수 있음. 중첩 영역 접합 및 지리 정합은 미완료.
- Godot 실행·성 선택·LOD 전환·메모리·프레임 성능·사용자 저장 복원은 이 환경에서 미검증.
- 게임 소스, 원격 저장소, Windows 프로젝트를 수정하지 않았음. 적용 지침과 자산 전달 단계임.
- 요청 해상도보다 낮게 출력된 파일을 인위적으로 확대해 고해상도로 보고하지 않았음. 최대 배율의 충분성은 실제 화면 픽셀 배율로 판단해야 함.
