# r3 원화 보충 검토

## 출발점

사용자가 r2의 실제 Godot 화면과 두 해상도 GUI 자동 입력 56건 통과를 보고했다. 재열기 카메라 초기화 문제도 현재 프로젝트에서 수정했다고 보고했다. 이 환경에서는 그 실행을 재현하지 않았다.

r2는 지형 위치가 다른 구간에 저해상도 승인 원본을 보여주므로 강·해안에 흐림이 남았다. r3는 이 구간을 채울 상세 원화를 준비하는 작업이다.

## 제작과 선택

현재 r2 표시 자료를 같은 좌표의 1536×1024 참조 화면으로 렌더했다. 승인 원본의 같은 영역을 함께 주고 내장 이미지 생성으로 흐린 구간을 수정했다. 첫 출력은 남쪽 강이 넓고 일부 지류 차이가 커 채택하지 않았다. 남쪽 강 폭과 연결을 한 차례 더 수정한 두 번째 이미지를 보충 후보로 선택했다. 원문 지시는 `R3_IMAGE_PROMPTS.txt`에 있다.

원화 PNG를 직접 확대 보간하거나 샤프닝해 완성본으로 표시하지 않았다. 실제 생성 결과의 크기는 1536×1024다. 게임에 연결하는 전체 지도나 r2 PNG의 바이트는 유지했다.

## 표시 방식

새 원화를 항등 UV의 바탕으로 그리고 현재 r2 망을 그 위에 올린다. r2의 불투명 영역은 이전 그림을 유지하며, 원본으로 되돌리던 구간에서만 새 원화가 드러난다. r3에 r2 변형 UV를 재사용하지 않는다.

별도 표시 코드로 r2와 r3를 같은 범위·해상도에서 렌더하고 대조했다. 후보 영역 밖의 픽셀과 r2의 불투명 영역은 변하지 않았다. 내부의 강·물가 선명도는 개선됐으나 바깥 저해상도 지형과의 선명도 차이는 남는다.

## 정합 평가의 한계

`r3_geometry_comparison.json`의 수치는 새 PNG 전체와 승인 원본을 색상으로 비교한 참고값이다. 최종 r2+r3 합성 화면의 지리 합격 점수가 아니다. 원본에서 회색·녹색으로 흐리게 그려진 좁은 지류는 색상 분류에서 누락될 수 있다.

새 원화가 저해상도 원본을 직접 사용하는 r2보다 모든 픽셀의 위치를 정확히 보존한 것은 아니다. 일부 강 폭·지류·물가 차이가 남는다. 이번 결과는 흐림을 줄이기 위한 **비교용 보충 후보**이며, 정식 교체·자동 LOD 적용 승인은 아니다.

## 완료하지 않은 항목

- r3 Godot 파싱·로드·렌더링·GUI 실행·성 선택·지원 경로 확인.
- 사용자가 직접 하는 수동 플레이와 저장 복원.
- 전체 35곳 성 바닥 정합, 영토 경계, 세계 지도 접합.
- 자동 LOD와 전체 지도의 확대 선명도 문제 해결.

현재 r2를 유지한 상태에서 r3 보충을 켜고 끄는 실제 비교를 `VSCODE_REQUEST.txt`에 요청했다. 기존 게임 규칙과 저장은 이 패키지가 변경하지 않는다.
