# r2 표시 보정 검토

입력은 사용자가 보낸 `승인 원본.png`, `상세 후보.png`의 동일 위치·5배율 실제 Godot 화면과 기존 지형 자산이다. 새 게임 캡처를 만들었다고 보고하지 않는다.

## 결과

- 좌표 보정 전후 비교에서 북한산성 북서 합류점, 당항성 서쪽 만, 국원 남쪽 물길, 하슬라~실직 해안의 색상 기반 수계 차이가 감소했다.
- 국원 남쪽의 잔여 차이가 가장 크다. 일부 물길과 바닷가는 승인 원본을 드러내며, 그 곳의 흐림은 남는다.
- 사각형 가장자리와 밝기 차이를 완화했다. 선명/흐림 변화가 모두 없어지는 완전한 접합은 아니다.
- 승인된 두 지형 PNG와 6개 거점 좌표를 유지했다.

## 수치 해석

`display_mesh_checks.json`은 RGB로 물을 추정한 뒤 작은 고립 영역을 제거한 참고 계산이다. 암석 그림자가 물로 분류되거나 작은 지류가 빠질 수 있다. r1의 미정제 색상 비교 수치와 직접 섞어 비교하지 않는다. 지리 정확도의 합격 점수로 사용하지 않는다.

과도한 자동 변형은 지형 뒤집힘 또는 국소적인 늘어짐이 생겨 제외했다. 전달 데이터는 변위를 부드럽게 한 후, **직렬화된 실제 UV 삼각형**의 면적 부호와 범위를 다시 검사했다. 5,808개 모두 방향을 유지하며 최소 면적비는 약 0.548이다. 이는 화면 망 검사이고 Godot 회귀 검사 횟수가 아니다.

## 실제 수행한 검증

- PNG 해시와 원본 추출 영역 일치.
- 보정 자료 UV/색/alpha의 유한성·범위·삼각형 방향.
- 표시 망 외곽 alpha 0.
- 별도 표시 코드가 그린 후보 범위 밖의 모든 픽셀이 승인 원본 미리보기와 동일.
- JavaScript 구문 검사와 동일 코드의 Node 렌더 결과 확인.

## 수행하지 않은 검증

- Godot 스크립트 파싱·런타임·GUI 통합 검사.
- 실제 브라우저에서 비교 버튼을 조작하는 GUI 검사.
- 전체 35개 성 바닥·영토 마스크·세계 지도 접합.
- 전체 캠페인·저장 복원. 이 자료는 저장 파일에 접근하지 않았다.

실제 게임의 자동 LOD는 승인 전 상태로 남긴다. `integration/INTEGRATE_KO.md`와 `VSCODE_REQUEST.txt`에 현재 코드에 연결할 범위를 명시했다.
