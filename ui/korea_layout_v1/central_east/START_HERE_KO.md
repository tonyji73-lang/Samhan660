# 중부·동해 상세 지형 — 표시 보정 비교판 r2

기존 파일명은 같고 내용은 **2026-09-21 r2**로 갱신했다. 이전 ZIP과 동일한 파일이 아니다.

이번에는 지형 PNG를 새로 그리지 않았다. 승인 원본과 상세 후보의 바이트를 유지하고, **상세 그림을 읽는 좌표(UV), 색감, 투명도**를 보정하는 코드와 데이터를 추가했다. 성 좌표와 실제 이동·지원·전투 규칙은 대상이 아니다.

## 이번 변경

- 중부·동해 후보의 강·해안 어긋남을 줄이는 표시 좌표 보정.
- 후보 사각형 가장자리 12 원본 픽셀을 부드럽게 혼합.
- 색상으로 추정한 수계가 여전히 다른 곳에는 승인 원본을 표시. 이 구간의 확대 흐림은 남는다.
- Godot용 draw-only 보조 스크립트와 보정 좌표 JSON.
- `RENDER_COMPARE.html`: 승인 원본 / 기존 후보 / 보정 후보를 같은 범위에서 전환하는 미리보기.
- `review/display_comparison.png`: 왼쪽 기존 후보, 오른쪽 보정 후보. **Godot 캡처가 아닌 별도 표시 코드의 결과**다.

## 확인 범위와 남은 일

보정 망 5,808개 삼각형에서 뒤집힘이 없고, 경계 투명도는 0이다. 두 원본 PNG의 해시가 이전 묶음과 동일하다. 표시 미리보기로 사각 경계 완화와 내부 선명도를 확인했다.

색상 기반 참고 비교에서 네 구간 모두 수계 어긋남이 줄었다. 이는 **지리 정확도 인증이나 게임 검사 통과 횟수가 아니다.** 국원 남쪽 지류, 일부 만과 원본으로 되돌리는 부분에는 차이·흐림이 남는다. 성 바닥 전체 정합, 전체 35곳 상세화, 영토 마스크, 세계 지도 접합도 완료가 아니다.

이 환경에서는 실제 게임과 Godot를 실행하지 않았다. 보조 GDScript는 현재 프로젝트에서 로드·실행 검증이 필요하다. 자동 LOD 전환은 계속 승인 전 상태다.

## 사용 순서

1. ZIP을 압축 해제한다. 프로젝트 전체에 덮어쓰는 ZIP이 아니다.
2. `RENDER_COMPARE.html`을 브라우저에서 열어 세 상태를 비교할 수 있다.
3. VS Code Codex에 `VSCODE_REQUEST.txt`를 실행하도록 요청한다.
4. 기존 `중부·동해` 비교 화면에 보정 후보를 연결한다. 최신 게임 스크립트를 옛 패키지 버전으로 덮어쓰지 않는다.

구체 연결은 `integration/INTEGRATE_KO.md`에 있다. 기존 `COMPARE.html`은 이전 원본/미보정 후보 비교를 그대로 남긴 자료다.
