현재 구현한 중부·동해 상세 비교에, 이번 ZIP의 r2 표시 보정판을 실제로 연결해줘.

1. START_HERE_KO.md와 integration/INTEGRATE_KO.md를 읽어. 현재 main과 기존 미커밋 변경을 보존하고 적용되는 작업 지침을 따라줘.
2. 승인 원본과 상세 후보 PNG는 기존과 바이트가 같아. 해시를 확인해 재사용하고, 새 central_east_display_layer.gd와 central_east_display_mesh.json을 기존 central_east 자산 위치에 연결해줘. 최신 approved_korea_map.gd나 settlement_overlay.gd 전체를 예전 파일로 덮어쓰지 마.
3. 기존 원본/후보 비교에 '보정 보기' 상태를 추가해. 원본 지형 다음, 영토·지원 경로·성·글자보다 먼저 보정 망을 그려줘. 미보정 후보와 보정 망은 중복해서 그리지 마. 성 좌표와 선택 로직은 유지해.
4. 실제 Godot로 로드 오류·경고·정점 색·투명도·그리기 순서를 확인하고 연결 문제를 수정해. 1280×720과 1920×1080, 같은 위치·5배율로 원본/기존 후보/보정 후보를 비교해줘.
5. 북한산성 북서 합류점, 당항성 서쪽 만·반도, 국원 남쪽 강 출구, 하슬라~실직 해안을 확인해. 일부 구간은 원본으로 되돌려 흐림이 남는 것이 이번 보정판의 한계야. 그것을 전체 정합 완료로 보고하지 마. 성 이동이나 전체 배율 변경으로 차이를 숨기지 마.
6. 비교 화면 닫기·재열기, 성 선택, 지원 경로, 하단 배치를 확인해. 기존 게임 규칙과 사용자 저장을 보존해.
7. 자동 LOD는 아직 켜지 마. 보정판의 실제 Godot 전후 캡처와 남는 지형 차이를 짧게 보고해줘. 문서만 추가하고 끝내지 말고, 현재 비교 화면 연결과 실행까지 진행해줘.

세력 선택 UI는 이 지도 확대 검토 이후에 진행해.
